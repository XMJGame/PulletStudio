# 自由创作

项目默认打开「项目创作」，点击「开始生成」，或进入创作画布创建/打开画布后点击「自由生成」。在画布中选中便签再打开，可将便签文字带入提示词。

选择已保存的工作流，粘贴正向提示词，按需填写负向词与来源。参数按当前固定工作流显示；图生视频需选择项目图片版本。点击「加入生成队列」后，Worker 持续执行，关闭窗口不会取消任务。未配置工作流时，在工作流中心添加连接、导入 API JSON 并验证保存。

新任务不需要剧本、Shot、完整卡或已编译提示词；不会偷偷创建占位镜头。已保存草稿工作流可用于自由探索，正式镜头的团队发布规则保持兼容。已归档目录不能新建任务；连接和项目权限始终生效。

完成的结果首先显示为「生成候选」，可以预览、下载原件、复用提示词，也可在选择图生视频工作流后将已有图片候选用作首帧。「存入素材库」显式将结果加入项目素材；重试不会生成重复版本或重复入库记录。「添加到画布」引用固定媒体版本，随后需保存画布。

管理员在工作流中心的「试跑与发布」点击「粘贴提示词试跑」，无需准备镜头。试跑产物继续作为独立证据，不能存入生产素材库或作为 Take。旧镜头试跑收在兼容选项中。

项目级入口展示项目所有通用任务，画布入口只看当前画布归属任务，30 条一页并支持更多记录。重新打开可继续查看。提交响应不确定时先「查询并恢复」，不能直接再点击生成来碰运气；原有租约、固定实例和安全核对继续使用。

旧剧本、分镜、结构、镜头编辑与编译提示词界面已经删除，也没有兼容菜单。G0 原型页面和源码已删除。历史 Board、媒体和任务来源继续通过后台授权读取。

每个项目可创建多张画布，在工具栏「切换 / 新建画布」选择或新建。布局与修订独立，资产库和媒体版本属于项目。系统按用户/项目记住上次画布；切换前未保存的草稿会提示处理，不能静默丢弃。

当前仍是一任务单产物、标量字段与单首帧 T2I/T2V/I2V 合同；音频、多图片、多输出和独立执行节点尚未完成。普通连线仍是注释关系。自由创作结果目前可逐个下载；现有标准包仍面向旧正式选片，通用候选打包在后续实施。

升级先备份并停止旧 Worker，执行 `npm run build`、`npm run db:migrate` 后重新启动 API 和 `npm run worker:generation`。日常自由创作无需启动文本分析或预演 Worker。新上下文的任务有 Worker 写入保护，防止旧二进制误处理。迁移 0039/0040 保留历史行与引用，不清空数据库。
