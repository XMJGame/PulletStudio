# ADR-007：语义资产及卡版本绑定

状态：采用。2026-11-05。承接 ADR-005/006，不重建现有卡历史或媒体表。

语义资产独立于物理媒体。稳定实体有固定项目/工作区/kind，内容和媒体角色在不可变实体修订下整体保存。媒体位置关联纳入修订事务，不单独改写历史修订；使用四张追加表与范围外键，不复制原文件，也不把供应商私有标识混入实体属性。

镜头引用保存在新卡 body.assetBindings 中，并通过 shot_asset_bindings 建立数据库可约束的固定修订索引。该索引按具体 Shot/cardVersion 追加，统一卡写入函数同步登记；现有手动附表、AI卡、原文来源及自动编号保持兼容。旧客户端未传新字段时沿用旧绑定，明确空数组才清空。当前同一镜头对同一实体只允许一个修订，造型/状态分体与连续性后续扩展。

读取卡可派生固定实体资料及变化提示，PromptArtifact 则冻结编译时完整实体/媒体快照；实时变化提示不属于旧不可变正文。新实体/媒体修订只使历史输入标记stale，不能改变卡里revisionId或重写旧Prompt。离线编译仍为手工交付，新增引用不自动变成可执行模型请求。

声音文字设定沿用项目读写权限；声音样本原件有独立限制，历史voice_sample引用持续生效，只允许上传者、项目管理/审核者及工作区管理者读取且需仍可访问项目。媒体分发前后都检查，下载/Range与普通GET同样受约束。无外部声音上传。细粒度授权名单、原始音频导入时分类及真实生成许可门禁另做。

当前只提供草稿修订和项目内引用，不模拟“已批准”，不开放跨项目共享。下一包需要追加实体版本审批事件和生成准入；随后Provider/ComfyUI引用明确批准版本，不能以文本字段或前端按钮冒充审批。权限和岗位继续分离。
