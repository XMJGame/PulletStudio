# ADR-011 资产与画布优先的轻量创作

2026-11-06，采用用户产品 V2。项目主入口为画布、素材与生成结果。剧本、AI 分镜、制作结构和 Shot 链路进入兼容区域，冻结新增业务。旧规划中的强制剧本、完整卡和正式发布前置由本决策替代。[完整产品方向](PRODUCT-V2.md)

Generation Job 归属项目，Shot 和 PromptArtifact 对通用任务可为空。原队列、Worker、Provider、路由和归档复用。外部提示词和固定首帧直接冻结进任务快照。自由创作只要求项目编辑权限与可访问的已保存工作流。正式镜头仍沿用原提示词、卡、审批及 Take 合同。

个人生成结果先保留为候选，可直接预览、下载和继续作为输入。明确保存时将同一个媒体资产加入素材库。已有媒体和历史审批保留。首批交付无 Shot 生成、画布入口、候选保存与复用，下一批完善画布独立生成节点、提示词资产和多输入。
