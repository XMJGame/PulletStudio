> 2026-11-06 产品 V2 优先：[当前方向](PRODUCT-V2.md)、[ADR-011](ADR-011-asset-led-creation.md)、[自由创作](LIGHT-CREATION.md)。资产/画布/工作流/通用生成是主线；已解除 Shot、完整卡、编译提示词和正式发布对自由创作的强制前置。下文旧镜头/剧本合同作为兼容参考，不再驱动新增核心需求。实际顺序唯一来源为 [IMPLEMENTATION-STATUS](IMPLEMENTATION-STATUS.md)。

Studio 通过 ComfyUI 原生 POST /prompt 提交任务。创作画布与镜头工作台共用 Generation Job。画布提交额外校验当前制作卡版本和工作流发布状态。有池工作区可使用自动选机和指定实例，无池工作区使用工作流绑定连接。[实例池生成](WORKFLOW-CENTER.md#使用实例池生成) · [画布生成](CREATIVE-CANVAS.md#镜头生成候选比较与选片)

在 Studio 的制作结构中打开一个镜头，选择“媒体生成”。管理员先添加 ComfyUI 连接及项目工作流。创作者选择当前制作卡的已保存提示词，核对文本，确认发送及生成资源消耗后加入队列。

也可先从项目“工作流中心”配置和查看工作流，导入时用只读节点图点选正/负/首帧/输出绑定，管理修订、归档和公开创作字段。见[中心使用与实际限制](WORKFLOW-CENTER.md)。另有有界节点/枚举依赖诊断；预览不执行生成，声明匹配不等于真实模型执行成功。

## 本地启动

在仓库根目录构建，再启动独立的生成 Worker。API、Web 与 Worker 使用同一份 `.env`、SQLite 和媒体根。Worker 需要现有 FFmpeg/FFprobe。连接凭据使用 `npm run setup` 初始化的 Provider 主密钥。

```powershell
npm run build
npm run worker:generation
```

## 连接与工作流

- 同时具有实例及工作区管理权限的账户可在镜头的“媒体生成”中展开配置。填写后端能访问的基础地址和可选的 Bearer 凭据。私有地址或 HTTP 需要在表单明确批准。工作区内可复用连接，各项目单独配置工作流。
- “测试连接”读取 `/system_stats`。保存工作流时，Studio 通过 `/object_info/{node_class}` 核对配置的正负文本输入与输出节点。此检查验证绑定，完整图能否执行由 ComfyUI 实际提交时校验。
- 从已运行的 ComfyUI 工作流导出 API 格式 JSON。普通画布 JSON 带节点和连线布局，须重新导出为 API 格式。工作流内的节点及其固定参数由管理员核对。工作流图保存在任务证据中，请将连接凭据填在连接表单。
- 正向与可选负向绑定指定节点和已有字符串输入。存在负向提示词时须配置负向绑定。输出指定保存节点以及远端历史中的字段，例如图片通常为 `images`。视频字段取决于工作流使用的保存节点。指定位置须返回单个文件。
- 编辑工作流保存为同目录的新修订，历史恢复也追加修订；旧定义和任务不被覆盖。归档目录阻止新任务但不停止已排任务；停用连接后尚未提交的任务无法发出，已提交任务在连接恢复后可查询。

当前支持文字生图、文字生视频，以及单张首帧图生视频。工作流可声明画幅、视频秒数和 seed 控件。末帧、多图参考、视频或音频输入、分辨率控件、多输出、批量和远端取消属于后续范围。当前可归档 PNG、JPEG、WebP、MP4、WebM、MOV。通过同一连接的 `/view` 读取指定输出，要求合法的 Content-Length。媒体类型、原件完整性与封面按现有归档规则验证。

## 可调生成参数

管理员在工作流配置展开“可调生成参数”，勾选需要提供给创作者的项目并指定节点及输入。默认值读取 API 图中的原始常量。画幅逐行填写显示名称和实际字符串，格式为 `名称=实际值`，实际值应完整匹配远端选项。秒数填写最小值、最大值及步长，步长从最小值起计算。seed 使用非负安全整数，范围上限不能超过 9007199254740991，也不能超过远端节点声明。

绑定只能指向不同的已有常量输入。秒数请绑定进入帧数换算前的上游秒数输入，保留图内的计算。保存时核对远端输入类型、可选值和范围。时长支持 INT/FLOAT，整型输入的范围及步长须为整数。画幅支持枚举或 STRING，seed 须为 INT。普通创作者选择已验证的参数，修改任何参数后需要重新确认发送。

工作流 API 增加可选 `parameters` 数组，三类条目均包含 `key/node/input`。画幅的 key 为 `aspectRatio`，附带 `options: [{label, value}]`。时长和 seed 的 key 分别为 `durationSeconds` 和 `seed`，附带 `min/max/step`，seed 的 step 固定为 1。生成请求增加可选 `parameterValues` 对象，字段名与 key 一致。省略的参数采用图中默认值，未声明的参数会被拒绝。配置读接口返回参数合同与 `defaultValue`。

任务冻结规范化后的请求值与实际提交图。同一幂等键可以重试相同值，变更参数会返回冲突。旧工作流继续使用图中原值。历史记录显示“请求参数”，归档完成后另显示由媒体检测得到的“实际产物”尺寸、时长及帧率。模型对时长和尺寸的对齐以生成文件为准。

G2-A2另外支持可选`fields`，Schema版本`studio.workflow-fields.v1`（省略按v1）。每项为自动UUID、label、node/input和text/number/boolean/enum合同，最多20项；默认取原图常量，保存核对远端声明。生成请求可传`fieldValues: {字段ID: 标量值}`，未知字段/错误类型或范围拒绝；旧parameters/parameterValues保留。创作者只填写名称对应的表单，历史按固定修订显示名称/值；列表刷新不替换已选修订。Worker对带字段的任务提交前复核声明。此Schema不包括音视频/多参考输入，不把任意文件名当媒体上传能力。

## 图生视频与 MiniMax H3

1. 在已经跑通的 ComfyUI 中打开工作流并导出 **API 格式 JSON**。官方 `video_minimax_h3_i2v.json` 是画布模板，使用你的版本导出 API 图可以保留实际节点、模型文件和参数。 [官方 MiniMax H3 模板](https://github.com/Comfy-Org/workflow_templates/blob/main/templates/video_minimax_h3_i2v.json)
2. 在 Studio 工作流设置选择“图生视频”。配置首帧为 API 图中的 `LoadImage.image`。正向词指向实际持有字符串的输入。如果 `MiniMaxH3ImageToVideo.prompt` 是直接字符串，可以绑定它。如果输入来自连线，应绑定提供文本的上游节点。
3. 输出指定原生 `SaveVideo` 的 API 节点。ComfyUI 0.44.0 的原生保存视频预览在历史中使用 `images` 字段。使用其他保存节点时按其实际历史配置。 [ComfyUI 0.44.0 历史字段实现](https://github.com/Comfy-Org/ComfyUI/blob/v0.44.0/comfy_api/latest/_ui.py#L396-L401)
4. 在镜头“媒体生成”选择已归档的项目图片版本。支持不超过 16 MiB 的 PNG、JPEG 或 WebP。确认后，Worker 校验并通过 `/upload/image` 将这张图发到已选连接的 `pullet-studio` 输入子目录，再把相对文件名绑定进提交图。任务记录显示所采用的图片及版本。远端输入文件可在 ComfyUI 侧管理。 [ComfyUI 上传接口实现](https://github.com/Comfy-Org/ComfyUI/blob/v0.44.0/server.py#L483-L497)

已在 ComfyUI 0.44.0 用官方 MiniMax H3 API 图和合成首帧实测，视频原件成功归档为镜头草稿 Take。当前输出画幅、时长由工作流配置决定。该次工作流设为 1:1、5 秒，实际视频为 640×640、约 5.17 秒。 [实机验收记录](IMPLEMENTATION-STATUS.md#2026-11-05-minimax-h3-单首帧图生视频实机验收)

## 自定义工作流

在“配置 ComfyUI 连接与工作流”选择本地 API 格式 JSON 文件。节点输入框会提示图中可用的节点编号与类型。分别指定节点编号和输入名称，提示词可绑定到已注册节点的字符串输入。首帧可绑定到远端声明为 `image_upload: true` 的现有图片文件名输入。输出使用配置的保存节点和历史字段。节点、模型和固定参数来自导入图。Studio 在保存时核对绑定，完整图的运行结果以 ComfyUI 实测为准。

当前每个任务处理一份 API 图、一张首帧和一个指定输出文件。使用多张参考图、专用上传接口或特殊输出结构的工作流需要相应扩展。

## 运行与恢复

Worker 在发出请求前复查当前卡、项目、连接、操作者及确切资产批准。选择历史提示词时应核对仍需沿用的内容。卡或项目设定变更后先保存新提示词。实际图、来源提示词和批准记录保存在任务快照。

- “等待 Worker”表示队列已持久化。可取消尚未提交的任务。
- “远端已接收，等待结果”表示已取得远端编号。Worker 周期查询该编号的历史。正常查询窗口为一小时，服务短暂不可用时延后读取。
- “需要核对”可能表示提交响应丢失、历史暂不可用或归档未完成。点“查询并恢复”仅查询历史或继续已有归档。较新的 ComfyUI 可以使用 Studio 提交的编号。旧版若另行生成编号，可从 ComfyUI 历史查到并填入。只有历史记录能证明与本任务关联才会继续取回。
- “结束本地跟踪”保留本地记录，并释放该镜头继续创建任务的入口。此前提交的远端任务可能仍在执行，请在 ComfyUI 检查。
- “已归档为镜头候选”表示原件已完成本地校验和登记，草稿 Take 与任务完成已在同一事务保存。结果出现在“镜头素材与候选”，也能从任务下载原件。如果远端执行期间已编辑镜头，候选仍归属该镜头，任务中显示实际采用的旧卡版本。若归档后 Take 登记失败，恢复会复用同一媒体。

自动验收使用标准路由模拟 ComfyUI，并使用真实 PNG 和 MP4 文件测试归档。实际兼容性须以目标主机的 API 格式图、模型和节点版本联调。
