# Pullet Studio 当前实施状态与计划

更新于 2026-11-06。当前方向为 [产品 V2](PRODUCT-V2.md) 与 [ADR-011](ADR-011-asset-led-creation.md)：资产、画布、工作流、生成与候选复用优先。L1 无镜头创作已完成本机自动化验收，下一批是 L2 画布独立生成/结果节点。旧状态完整保存在 [V2 前快照](history/IMPLEMENTATION-BEFORE-V2-2026-11-06.md)。

## 本轮实际完成

- 新项目默认进入「项目创作」，提供直接生成、素材、画布和工作流入口。剧本、分集与镜头、制作结构、AI 分镜收进「兼容制作工具」；移除右上角 G0 原型入口。
- Generation Job 继续使用原表、原 Worker/Provider/Storage/实例路由。通用任务直接归属项目，可选 Board；不要求 Shot、制作卡或 PromptArtifact，不创建影子镜头。直接冻结外部正负词、来源、工作流修订、参数和首帧。旧 Shot 路径不变。
- 自由创作可以使用已保存的固定草稿工作流。项目权限、连接授权、归档禁用、远端类型验证仍生效；正式镜头的发布与审批合同保留。
- 通用结果归档后先为库外候选，不创建 Take。可预览、下载、复用提示词、选用图片作为下一次 I2V 首帧、明确存入素材库、固定引用回画布。入库幂等，不复制文件或伪增媒体版本。
- 工作流管理员可直接粘贴提示词试跑，无需创建镜头；试跑证据继续隔离，不能混入生产资产或 Take。旧镜头试跑保留兼容入口。
- 已保存画布工具栏直接启动通用生成；选中便签时带入文字。关闭窗口后任务继续，重开可查看当前画布任务。项目入口可查看项目全部通用任务，30 条一页。
- 增量迁移 0039 保留同一 Job 表及原数据/索引/历史保护，增加可选 Board 和库内标记；0040 增加项目任务索引和通用任务专用 Worker 租约保护。旧媒体默认已入库。过期 Worker 不能领取新上下文任务，包括旧实例池 Worker，升级后须重启 Worker。

实施合同见 [L1](modules/LIGHT-CREATION-L1.md)，使用方式见 [自由创作](LIGHT-CREATION.md)，取舍与后续阶段见 [V2 审计](architecture/PRODUCT-V2-AUDIT.md)。

## 后续开发顺序

| 优先级 | 下一包 | 具体修改与退出条件 |
|---|---|---|
| 1 | L2 正式画布创作节点与结果/任务入口 | 先写 Board 新版合同和兼容读取；复用现有生成表单/Job，增加提示词、生成、结果节点和明确数据绑定；独立任务/结果列表，持续保留重启和权限控制，不重建队列 |
| 2 | L3 多输入/多输出 | 从真实角色三视图或已就绪工作流开始；扩展 Workflow Schema、Provider/Worker 和结果关联，不假设一任务只能有一个媒体；逐步接首尾帧、参考图组、音频 |
| 3 | L4 资产复用和通用交付 | 外部提示词模板/资产、角色参考角色位、任选媒体 ZIP/manifest；不要求先批准 Shot Take，原正式包兼容 |
| 4 | L5 真实生产验收和部署 | 待用户模型就绪时核验具体合同/设备；团队日常素材、实例和存储反馈优先，再按需批量、共享/审核，不提前做全套企业流程 |

每包先确定 DB/API/UI/失败处理及验收，完成后必要测试并更新本页。旧 G2-C2 后的团队岗位/镜头批次/脚本增强计划已被此顺序替代。系统继续服务通用影视创作，不硬编码题材、作品、硬件地址或模型。

## 本轮明确未完成

自由生成现为复用表单与便签输入的第一步；画布还没有独立执行节点、类型化数据连线或自动执行图。仍是一任务单产物；多图片/视频/音频输入、多输出、提示词资产、收藏/归档、无镜头打包、跨项目模板、Mounted/S3、正式 LAN/TLS/多人规模验收均未完成。旧高级 UI 仍有可渐进简化之处，不在本轮一次推倒。
