# Pullet Studio 当前实施状态与计划

更新：2026-11-05。G1在19536a8/G0基础上完成正式引用画布，主栈NestJS/React/Drizzle/SQLite不变，下一包G2复用既有生成/Take闭环。标准交付e828d8c、整理0e6a21c保留。本文件是唯一实时状态/任务顺序，阶段过程见history，入口见[文档导航](README.md)。

## 产品边界与当前判断

生产工作台＋创作画布，共用Production Core、Provider、Storage与多人工作区。Pullet负责剧本→分镜→完整卡/提示词→生成或导入→候选审核/选片→素材交付；专业后期在外部软件完成。保留媒体预览、镜头顺序/计划时长和可选低清故事板预演，不新增多轨、转场、关键帧、调色、合成或专业混音。声音素材与可靠SRT交付仍可按来源实施，OTIO/FCPXML需逐软件验证。依据[ADR-009](ADR-009-production-and-postproduction-handoff.md)，不再按旧剪辑路线施工。

**已经具备可运行的基础生产链，但尚未完成团队V1和正式部署验收。** G1画布已接项目/单元、固定镜头/资产/媒体、原权限及服务端修订；G2生成/结果接入尚未做。真实I2V已独立跑通，文本/T2I/T2V主要依据Mock。不能以页面或测试数量推算整体百分比。[ADR-010](ADR-010-comfy-instances-and-board-boundary.md)冻结原生/prompt＋多独立实例、默认auto/高级manual，不接Distributed专用API；调度排G2后，不声称已实现。
