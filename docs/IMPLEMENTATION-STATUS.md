## P2-B1 实施合同（已完成基础范围，编码前记录）

- 实现原始模型草案上的人工候选编辑、整份拒绝/重开和采纳。原 analysis_proposals 不改；以 proposal_reviews 当前指针 + proposal_revisions 追加修订/决定，原始草案为虚拟 v0，读操作不新增记录。
- 候选顺序/数量本阶段固定，编辑已有镜头卡字段与范围内原文引用，所有写入 expectedVersion；草案编辑用项目编辑权限，拒绝/重开/采纳用独立 review 权限（工作区管理员、项目管理、REVIEWER），不会给审核者通用镜头编辑权限。
- 采纳整份候选到项目直属或指定制作单元，须明确确认计划时长（沿用现有 1–3600 整数秒镜头计划，不冒充实际声音测量）。事务原子写入正式 Shot、完整 shot_card_revisions、script_spans、shot_script_spans、proposal_adoptions、审核版本及审计；编号依旧后台生成。任何失败全部回滚，重复相同采纳返回既有映射。
- 修订原文/项目设定较分析快照更新时显示差异警告并须明确确认；不自动重定位来源。已采纳草案不再编辑/拒绝/重开，后续修改正式镜头追加制作卡版本并保留采纳快照。
- 旧镜头编辑接口保留：已有完整制作卡的镜头，修改画面/运镜/对白/时长/方式时同步追加卡版本；其他字段和来源保留。手动旧镜头不虚构完整卡。支持查看制作卡、原文及历史版本，后续 PromptCompiler 直接使用该版本。

- 增量表/索引/约束/不可变触发器，迁移前在线备份，旧表/原文/模型结果不重建。测试先补角色矩阵、来源完整性、409、重放/并发/回滚、时长未确认、旧来源确认、审核不可逆、正式卡续写、撤权/回收站、重启与浏览器手机/双窗口流程。

## P2-A 实施合同（已完成基础范围）

- 增加工作区文本连接（通用 Chat Completions compatible adapter），名称/模型/端点/JSON 输出模式/输出上限/超时分别配置；不指定某个厂商或默认模型。新增端点由已加入工作区且有工作区管理权限的实例管理员批准，私有地址单独明确授权；普通成员不可配置凭据。
- Provider 凭据以 AES-256-GCM、随机 IV、connection/workspace AAD 加密保存，API 只返回 hasApiKey；master key 由本机 setup 写入忽略的 .env，不打印。保持既有初始化密钥和用户数据。
- 网络只允许已批准连接；公网默认 HTTPS，DNS 解析检查所有地址并固定实际连接 IP，拒绝重定向和 metadata/link-local 地址；私有/本机连接必须显式批准。请求、响应、超时均有界，不返回供应商原始错误或密钥。
- 追加 text_connections、text_model_profiles、analysis_runs、analysis_proposals，连接/模型分表。任务冻结连接版本、剧本修订、设定和原文范围，Idempotency-Key 防重复创建。单次原文最多 8,000 UTF-16 单元，按稳定来源块拆分；大篇不整稿一次提交模型。用户输入的上下文摘要为明确选择的附加上下文，不自动发送其他原文。
- 独立 Node Worker，数据库事务领取/租约/心跳；发送前重新检查成员、项目状态和连接版本。准备阶段失租可恢复，已提交后失租/断线进入 NeedsReconciliation；仅明确 429 可按 Retry-After 自动重试，5xx 和不确定提交保守转人工核实。显式取消为停止跟踪，不虚称远端已取消；再次排队须确认重复调用风险。
