# Pullet Studio 当前实施状态与计划

更新于 2026-11-06。当前方向为 [产品 V2](PRODUCT-V2.md)、[项目资产/多画布补充](PROJECT-ASSETS-AND-MULTICANVAS.md)与 [ADR-012](ADR-012-remove-retired-creation-ui.md)。已完成无镜头创作、多画布、提示词库及单节点执行。下一批先统一资源授权，再按已验证的工作流扩展多模态输入和输出。

## 本轮实际完成

L2-C：新增生成节点和结果节点。便签提供 TEXT，固定图片提供 IMAGE，选择与拖线保存同一种输入绑定。旧注释线保留原语义。选择工作流后保存并执行，任务冻结画布修订、绑定、正负词、首帧和参数。节点内可查看任务、预览候选并去重加入画布。相同修订与调度在同一标签页刷新后可重试原请求。采用 v1 兼容扩展，复用现有快照、队列和权限。详见[使用指南](CREATIVE-CANVAS.md)和[验收记录](history/BOARD-EXECUTION-L2C-2026-11-06.md)。

L2-B：项目提示词库独立保存普通文本，支持标题、正负词、标签、来源、推荐固定工作流、搜索、复制与不可变修订。项目首页、生成窗口和画布使用同一库窗口；生成文字/便签可存库，固定版本可用于生成或插入同项目任意画布，完整保留16000字符范围内的正负词。任务冻结实际文本及来源版本，库修改不改旧任务；编辑文字解除绑定。项目权限、CAS冲突保留草稿、幂等与事务审计贯通。0041只增两表和保护，旧调用/便签兼容；没有第二队列、编译器或自动执行图。见[使用指南](PROMPT-LIBRARY.md)、[合同](modules/PROMPT-LIBRARY-L2B.md)及[验收](history/PROMPT-LIBRARY-L2B-2026-11-06.md)。

以下 L2-A/L1 能力继续复用：

L2-A：删除 47 个废弃文件，包含 G0 全部源码/HTML/测试/构建/CI 入口，以及旧剧本、AI 分镜/提案、分集/结构/镜头编辑、提示词编译、预演/旧包前端及专用浏览器 flow；另删除无实际脚本/部署引用的旧 PostgreSQL/Redis Compose 示例。旧「兼容制作工具」彻底移除，不移动到保留目录。生成/素材窗口与试跑仅保留项目级交互，主页面不再请求分集/镜头。新增多画布切换/新建、未保存草稿保护与按用户记住上次画布；同项目三张画布共用资产和 I2V 入库结果已验收。详见 [L2-A 合同](modules/CREATION-CLEANUP-L2A.md)与 [新依赖路线](architecture/ASSET-CANVAS-IMPLEMENTATION.md)。

以下 L1 能力继续复用，旧界面去留以本轮 L2-A 覆盖：

- 新项目进入「项目创作」，提供直接生成、素材、画布和工作流入口；已有画布按用户/项目恢复上次打开。旧制作入口与 G0 已删除。
- Generation Job 继续使用原表、原 Worker/Provider/Storage/实例路由。通用任务直接归属项目，可选 Board；不要求 Shot、制作卡或 PromptArtifact，不创建影子镜头。直接冻结外部正负词、来源、工作流修订、参数和首帧。旧 Shot 路径不变。
- 自由创作可以使用已保存的固定草稿工作流。项目权限、连接授权、归档禁用、远端类型验证仍生效；正式镜头的发布与审批合同保留。
- 通用结果归档后先为库外候选，不创建 Take。可预览、下载、复用提示词、选用图片作为下一次 I2V 首帧、明确存入素材库、固定引用回画布。入库幂等，不复制文件或伪增媒体版本。
- 工作流管理员直接粘贴提示词试跑，无需创建镜头；试跑证据继续隔离，不能混入生产资产或 Take。旧镜头试跑表单已删除，历史证据仍能读取。
- 已保存画布工具栏直接启动通用生成；选中便签时带入文字。关闭窗口后任务继续，重开可查看当前画布任务。项目入口可查看项目全部通用任务，30 条一页。
- 增量迁移 0039 保留同一 Job 表及原数据/索引/历史保护，增加可选 Board 和库内标记；0040 增加项目任务索引和通用任务专用 Worker 租约保护。旧媒体默认已入库。过期 Worker 不能领取新上下文任务，包括旧实例池 Worker，升级后须重启 Worker。

实施合同见 [L1](modules/LIGHT-CREATION-L1.md)，使用方式见 [自由创作](LIGHT-CREATION.md)，取舍与后续阶段见 [V2 审计](architecture/PRODUCT-V2-AUDIT.md)。

## 后续开发顺序

| 优先级 | 下一包 | 具体修改与退出条件 |
|---|---|---|
| 1 | L3-A 授权共享 / L3-B 多模态 | 统一 ResourceAccess 后才接 Project/User 授权；贯穿预览/原件/Worker/导出/撤销，再按已就绪工作流支持多输入/输出，R2V 单独实机 |
| 2 | L4 通用交付 | 外部提示词/角色参考角色位、任选媒体 ZIP/manifest，无 Shot 交付；原正式包和历史来源仍可读 |
| 3 | L5 真实生产验收和部署 | 待用户模型就绪时核验具体合同/设备；团队日常素材、实例和存储反馈优先，再按需批量、共享/审核 |

每包先确定 DB/API/UI/失败处理及验收，完成后必要测试并更新本页。旧 G2-C2 后的团队岗位/镜头批次/脚本增强计划已被此顺序替代。系统继续服务通用影视创作，不硬编码题材、作品、硬件地址或模型。

## 本轮明确未完成

画布每次手动执行一个节点，单任务单产物。自动执行整图、多图片/视频/音频输入、多输出、收藏/归档、无镜头打包、指定项目/用户共享、跨项目模板、Mounted/S3、正式 LAN/TLS 与多人规模验收未完成。提示词库尚无收藏、最近使用、变量模板和删除。本轮画布链路以 Mock 验收。
