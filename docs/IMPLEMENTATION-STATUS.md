同包将原型中已验证的视频播放入口和时长提示接到正式节点，使用现有已授权媒体 URL、原生播放器和缩略图。点击后才加载，同时仅保留一个节点播放器；关闭、离开可见区域或切换画布应释放播放状态。不改输入绑定、不把预览结果自动写入下一任务，不增加自动播放背景视频。

本包已通过真实接口下的主视图语义、无隐藏首页、Esc 不退出项目、弹窗焦点/粘贴隔离、未保存离开保护、刷新恢复、直接导入和只读回归。节点预览验证真实 MP4 解码、按需加载、单播放器切换、关闭、失败占位、刷新不播放及原固定引用不变。正式空画布截图覆盖 1920×1080、1440×900、1366×768、390×844，并检查深色和桌面视频节点。后续结果以上方当前阶段和验证表为准。
