# 工作流中心（G2-A1）

在正式项目工作台点“工作流中心”，无需先创建镜头。左侧浏览/搜索该项目已保存配置，右侧沿用原连接/导入/绑定流程；原镜头“媒体生成”的配置入口继续可用，二者使用同一个GenerationSettings和后端服务。

只有既有`canConfigure`权限（实例管理员且具工作区管理权限）能配置连接/工作流；其他项目读者只看工作流名称、能力、连接启用状态和已暴露参数摘要，不返回服务器地址、凭据或原始技术图。连接仍是受信后端配置，停用影响生成可用性，没有新增实例调度。

## 导入与技术图

1. 选择已有连接，填写配置名称和生成方式，上传或粘贴ComfyUI **API格式JSON**。沿用1–200节点/160KB限制，不接受普通界面布局JSON。
2. 点“预览节点图”，只读查看class_type及输入连接。可拖视口/缩放/小地图，节点本身不能移动、改线或执行；也可用“选择工作流节点”下拉操作。
3. 选节点，再选常量输入，明确“设为正向文本/负向文本/首帧图片”；“设为输出节点”只填输出绑定。首帧只在I2V方式出现；手工绑定字段仍保留。其他参数目前沿用画幅枚举/时长/seed，通用自定义字段尚未实现。
4. 图中默认只显示字段名/类型，不展示可能含密钥、路径的全部常量；不加载其中的外部媒体URL，不执行HTML、脚本或节点代码。技术预览最多600条线、20条警告、所选节点100个常量字段，超预览上限不会修改原JSON。
5. 缺端点/循环明确提示，不能把预览当执行可用性保证。点“验证绑定并保存”调用原服务端/object_info绑定校验，通过后保存独立不可变配置；失败保留JSON/名称/绑定。该校验目前只覆盖绑定相关节点，不等于整图模型依赖已通过。

关闭未保存的中心输入会要求继续或明确丢弃，刷新有原生未保存提示；草稿只在当前页面，不写Board/localStorage，也不承诺崩溃恢复。中心不发生成请求，实际任务仍在镜头入口选择Artifact/固定媒体并确认资源消耗后创建。

## 当前限制与下一步

本包只新增Web入口/组件提取/技术预览，**无DB迁移或新API**；仍共用generation-config、generation-connections、generation-workflows、原鉴权/校验/审计。列表沿用原接口最多100配置/50连接；没有读取既有配置原图、编辑/家族修订、工作流审批/归档或通用Schema。既有创建配置API尚无请求键幂等，本包不自动重试不确定保存，用户应先刷新列表核对，避免重复创建。

下一包G2-A2补版本关联、Schema和有界节点/模型依赖报告；原generation_workflows定义与Job外键保留，不能覆盖历史。随后受控测试、G2-B正式画布简化生成/结果比较/Take，G2-C独立实例auto/manual。技术配置中心与正式创作Board分工，完整ComfyUI编辑器和复杂剪辑器不在V1范围。

参考取舍见[hero8152能力对照](architecture/HERO-INFINITE-CANVAS-REVIEW.md)，源码/资源未复用。验收命令`npm run test:workflows`（包含图解析和独立浏览器），端口3112/5192与`test:boards`共用隔离启动配置，二者应顺序运行；原生产测试使用不同端口。无真实模型调用。
