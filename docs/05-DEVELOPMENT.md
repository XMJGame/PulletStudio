## 备份恢复

运行 `npm run db:backup` 获取 `data/backups/` 中的新快照。不要直接复制正在使用的主数据库文件：已提交内容可能仍在 WAL 中。备份目录应在部署时增加外部备份副本，目前仅为本机快照。

恢复时先停止 API/Worker。保留原数据库及关联的 `-wal`、`-shm` 文件，不直接覆盖它们；把选定快照复制为新的本地数据库文件（例如 `data/restored.sqlite`），在 `.env` 更改 `DATABASE_PATH` 后重启。检查 `/health/ready`、项目和镜头数据；原库留作回退。后续素材阶段需同时备份媒体对象与配置密钥，当前快照不代表完整 V1 灾备。
