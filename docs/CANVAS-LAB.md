# 创作画布交互原型（G0）

G1正式画布现已独立接入项目/单元、固定业务版本、服务端修订与权限，使用说明见[CREATIVE-CANVAS](CREATIVE-CANVAS.md)。本页继续只描述G0实验，不把其localStorage、示例节点或性能数字冒充正式业务数据。

项目工作台右上角点击“创作画布原型”，或打开同一服务的 `/canvas-lab.html`。这是独立实验入口，不读取或改动项目数据，不调用模型，也不上传本地文件。

## 可以试什么

- 参考图＋提示词 → 生成配置 → 多方案比较；选中节点，在右侧改名称/备注，展开比较三张合成示意图并标记主方案。标记不等于正式Take批准或选片。
- 拖动节点，空白处框选、Shift多选；滚轮缩放，空格/中键或“平移”工具移动视口。“查看全图”适应所有节点，“回到起点”返回第一组。
- 点击输出端口再点目标输入端口；React Flow底座也支持拖线。引用类型不匹配、重复、自身或循环会被拒绝。连接不执行生成，不假装工作流支持任意输入。
- 选中视频/声音/图片，在检查器选择本地文件预览。仅当前浏览器读取，不自动播放；离开节点释放文件，重新打开需重选。每文件上限128MiB，浏览器不支持的编码可能无法播放。
- “保存本机布局”保存实验便签/布局/视口，不保存媒体内容或临时URL，也不写项目数据库。刷新恢复最近保存；JSON导入失败保留当前编辑。“30/50节点样例”明确重载样例，不覆盖已保存布局。

右侧“原型对比与布局文件”可切换React Flow与最小DOM视口，查看性能记录、导入/导出布局和依赖许可。两者共享模型/卡片/验证；DOM对照没有小地图、完整拖线/键盘边操作等成熟能力，不作为正式选型建议。

实验JSON最多200,000字符/100节点/200边，名称100字符、备注4,000字符，位置/缩放有界，只接收已知字段/节点类型及有效引用。不支持任意媒体URL、脚本或远程插件。实验样例不迁移为未来正式资产；正式版本会使用服务端BoardRevision、项目权限和并发保护。

## 性能观察

点击“观察4秒交互性能”后持续平移/缩放。记录rAF总样本与最近150ms内有指针/滚轮事件的活动帧样本、活动帧间隔p95/最大值、longtask、已挂载卡片数、视口和浏览器。交互事件少于10或活动帧不足30时明确不作结论。

这些是当前机器/浏览器/合成缩略图的观察，不是完整呈现延迟、GPU基准或长片生产保证。不会同时解码50个视频；正式媒体解码、网络、权限和数百节点仍需G1之后测试。对照使用相同样例/共享缩放控件和往返平移，避免不同滚轮曲线导致观察场景不同。

## 开发验收

`npm run test:canvas` 独立启动Vite/5191，不启动生产API/Worker。播放测试使用FFmpeg合成文件；浏览器默认Edge，可用PLAYWRIGHT_CHANNEL指定Chromium。与原test:e2e分开，CI分别运行。截图与JSON性能记录在忽略的test-results目录。

本包借鉴infinite-canvas的交互，实际读取固定提交9cd3dea的视口/资源解析/生成输入/配置面板/结果组/Registry源码，未复制或运行上游代码。React Flow锁定12.12.1，包内MIT许可及新增依赖通知随Web构建保留，页面仍显示默认署名。核验及选型见[ADR-008](ADR-008-creative-canvas-reference.md)和[本阶段记录](history/CANVAS-G0-2026-11-05.md)。

G1才接正式项目/单元Board、固定资产/镜头引用、权限、历史版本与CAS；G2才接现有生成任务与Take比较/审批。当前不声称已交付团队创作画布。
