# 画布直接导入验收

本地文件经原上传意图、二进制传输、探测、归档与固定版本解析进入 Board 草稿。素材窗口和新入口使用同一上传函数。拖放坐标考虑当前平移和缩放，批量排布使用足够的媒体间距。自动加入其他节点时也按当前节点尺寸搜索空位。

| 检查 | 结果 |
|---|---|
| 类型、格式与构建 | 通过 |
| 正式画布浏览器 | 11 项通过，新增批量 PNG/MP4/WAV、剪贴板图片、文件选择、正文粘贴、非重叠排布与恢复场景 |
| 工作流与提示词浏览器 | 11 项通过 |
| 原项目入口浏览器 | 1 项通过，包含素材窗口手工上传 |

恢复场景分别在传输前中断、服务器完成传输后丢弃响应、服务器建立意图后丢弃响应。重试后逐次核对上传记录、素材数量和画布节点，没有重复创建。另验证非法格式、超过 20 份、只读、固定引用保存和重载。测试使用独立 SQLite 与真实合成媒体，剪贴板由浏览器 ClipboardEvent 触发，生成回归使用 Mock ComfyUI。

本地截图为 `test-results/canvas-direct-import.png`、`test-results/direct-import-content-failed.png` 与 `test-results/direct-import-mobile.png`，桌面与 390px 导入窗口均已检查。文件对象和待重试列表保留在本页，页面关闭后需重新选择文件。媒体归档和画布保存是两个步骤，导入成功后会提示保存草稿。
