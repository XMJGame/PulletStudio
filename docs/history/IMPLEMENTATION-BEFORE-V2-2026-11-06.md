# Pullet Studio 当前实施状态与计划

更新于 2026-11-06。G2-C2 已实现自动选机、手动指定、事务容量预留及固定实例恢复。软件闭环通过双 Mock 验收，真实双机验收待执行。[G2-C2 验收](../history/COMFY-INSTANCES-G2-C2-2026-11-06.md)

## 产品边界与当前判断

生产工作台＋创作画布，共用Production Core、Provider、Storage与多人工作区。Pullet负责剧本→分镜→完整卡/提示词→生成或导入→候选审核/选片→素材交付；专业后期在外部软件完成。保留媒体预览、镜头顺序/计划时长和可选低清故事板预演，不新增多轨、转场、关键帧、调色、合成或专业混音。声音素材与可靠SRT交付仍可按来源实施，OTIO/FCPXML需逐软件验证。依据[ADR-009](../ADR-009-production-and-postproduction-handoff.md)，不再按旧剪辑路线施工。

基础生产链覆盖剧本到选片与交付。创作画布可用发布工作流生成镜头候选，任务由服务端持续执行。官方单首帧 I2V 已在早期阶段实机验收，G2-B 画布闭环使用隔离 Mock。团队 V1 的部署、多实例和实际生产规模验收仍在计划中。[ADR-010](../ADR-010-comfy-instances-and-board-boundary.md)
