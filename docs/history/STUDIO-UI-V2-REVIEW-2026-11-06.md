# Studio UI V2 首次视觉评审

基线 `79f17e1`。设计评审原型运行在独立开发入口。现有项目、画布及任务界面仍由原入口提供。工作分支处于视觉评审阶段。

- 交付项目首页、空画布、创作画布。共享令牌和基础组件见 `apps/web/src/shared`，项目和画布布局见 `apps/web/src/features`，可交互的示例、原创图像和短片位于 `apps/web/src/design-review`。
- 评审用例 3 项。覆盖搜索、打开与新建示例项目、空画布、资源拖放、首帧连接、参数、失败保留提示词、重试、播放、入库与复用、切换画布及深浅主题。截图见本地 `test-results/studio-ui-v2/`，含三档桌面、手机和任务状态。放大检查用有效视口等效测试。
- 原生产基线回归为 216 项 API、7 项画布、11 项工作流浏览器及 4 项图解析。类型、格式与生产构建通过，评审入口未进入生产产物。

实际生成使用模拟状态和本地合成短片。业务接入、旧页面迁移、正式存储与权限验证、真实 ComfyUI 和最终 PR 均在评审之后。启动命令和下一阶段条件见[重建合同](../modules/STUDIO-UI-V2.md)。
