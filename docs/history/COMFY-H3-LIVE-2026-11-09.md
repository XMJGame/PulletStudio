## 工作流适配与限制

- 原始 JSON 不改。副本将模型名补为 ComfyUI 当前实际枚举中的子目录；不移动、下载或复制模型文件。
- seed 37；视频请求 5 秒，实际帧对齐后约 5.17 秒。I2V 为方形，其余为 16:9；测试分辨率 0.4 MP。T2I 原副本 0.9 MP 降为 0.4 MP 验证，不能当作所有分辨率/显存组合已通过。
- T2I 默认 `minimax_h3_video_vae_fp16.safetensors` 本机不存在，实测改用已有 `MiniMax/minimax_h3_video_vae_int8_convrot.safetensors`。这是 INT8 VAE 适配版，不是原 FP16 配置的验收结论，不声称画质/性能等价。
- I2V 首次保存画幅失败，原因是 ResolutionSelector 公开新式 `COMBO + options`。修复共享元数据解析、画幅和公开字段验证、依赖检查，继续拒绝非法值和上传字段。旧数组枚举及 STRING 继续兼容。
- 后端全量 **287 项通过**，含新旧 COMBO 的真实 HTTP Provider 专项；构建、类型、格式、文档链接检查通过。真实任务只提交一次，不因等待重复调用模型。
- R2V 缺 `minimax_h3_ref2va_pruned_int8_convrot.safetensors` 和 `minimax_h3_ref2v_turbo_4step_v0.1_comfyui_bf16.safetensors`，用户明确选择稍后准备，因此未提交、不下载，也不以 I2V 权重替代。Music 3 不属于本次 H3 三类范围。
