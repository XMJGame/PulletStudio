# Studio UI V2 分支整体验收

## 已实现范围

| 创作步骤 | 正式入口与复用路径 |
|---|---|
| 项目与恢复 | 项目卡片、搜索、最近使用、自动编号、空项目创建画布、按用户恢复画布 |
| 参考素材 | 原媒体上传与探测、固定版本、资源库、拖入画布和首帧绑定 |
| 工作流 | API JSON 文件或正文、技术图、输入输出映射、参数、修订与试跑 |
| 生成 | 画布浮动面板、提示词库、保存后提交、固定版本、调度和断线恢复 |
| 候选与复用 | 图片/视频预览、加入画布、显式入库、同项目其他画布复用 |
| 权限与故障 | 只读、撤权、不可用引用、保存冲突、未保存输入保护及历史读取 |

素材、任务和项目等弹窗通过 React Context 跟随应用主题，Portal 继续沿用原焦点与退出逻辑。删除经 TS/TSX 引用核对的 109 个旧选择器，共 498 行，包括旧侧栏、镜头编辑布局、剧本证据、提示词编译和预演/交付页面样式。画布删除重复的旧蓝色令牌，统一读取共享主题。

## 验收方式

| 验证 | 结果 |
|---|---|
| 类型、构建、格式 | 通过 |
| API | 216 项通过 |
| 图解析 | 4 项通过 |
| 画布浏览器 | 原 8 项回归通过，新增完整 UI 链单独通过 |
| 工作流浏览器 | 11 项通过 |
| 项目入口浏览器 | 1 项通过 |

新增完整 UI 用例从项目列表创建项目和画布，通过素材窗口上传并归档参考图，通过工作流中心添加连接并导入 I2V 工作流，映射首帧、正向词与输出。回到画布执行后预览可解码视频、加入画布、入库，再到另一张画布引用同一媒体版本。重载恢复位置，切换深色后检查手机素材窗口。业务写入全部通过界面操作，API 用于准备登录身份与读取结果断言。

本地截图在 `test-results/`，包括 `studio-acceptance-new-project.png`、`studio-acceptance-media-light.png`、`studio-acceptance-result.png` 和 `studio-acceptance-media-dark-mobile.png`。

## 评审边界

外部模型由本地 Mock ComfyUI 承担，上传、存储、探测、Board 和 Generation 使用正式实现与隔离测试库。真实模型与团队规模验收仍待安排。素材和通用任务窗口当前采用表单和列表交互。

当前运行范围为单节点、单首帧、单输出。跨项目授权、多媒体输入输出、收藏与归档、任意素材交付包、本地粘贴/文件拖入以及远程存储仍在后续计划。
