## 性能观察与取舍

本机Windows11，Headless Edge156，页面1440×1000，画布1136×788。两适配器共享样例/缩放控制、适应全图后的往返中键平移，4秒内持续操作；视口外节点不挂卡片。p95来自最近150ms有指针/滚轮事件的活动rAF帧，非空闲帧统计。它不是端到端呈现延迟或专业GPU基准。

| 适配器/节点 | 活动样本 | 活动帧间隔p95 | 最大帧间隔 | longtask | 记录末尾挂载卡片 |
|---|---:|---:|---:|---:|---:|
| React Flow / 30 | 240 | 16.8ms | 16.9ms | 0 | 24 |
| React Flow / 50 | 240 | 16.8ms | 16.8ms | 0 | 46 |
| DOM / 30 | 232 | 16.8ms | 83.3ms | 0 | 24 |
| DOM / 50 | 240 | 16.8ms | 16.8ms | 0 | 46 |

这是一次受控观察，DOM30有帧间隔尖峰，不能仅凭p95说所有帧稳定或宣称某底座更快。当前没有性能证据要求替换React Flow。对照适配代码约121行（Flow）与285行（DOM），共同模型/节点/界面另计；行数不是完整成本，但DOM仍缺小地图/完整拖线/边键盘等维护责任。继续React Flow作为G1底座，保留DOM只作实验，不同时维护两个正式引擎。
