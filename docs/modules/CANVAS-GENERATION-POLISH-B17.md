# B17 · 生成卡片与常用参数收敛

仅 Web，复用固定工作流摘要、Board 具名输入、任务列表及已有参数 Schema。无 DB/API/Worker、Provider 或随机策略变化，不把未映射参数显示为可用。

- 卡片去掉重复标题与常驻 TEXT/IMAGE 文案，保留可访问端口名称/悬停提示。显示读取到的固定工作流名称、提示词摘要、实际连接的素材及用途和最近任务状态；刷新尚未读取时明确提示，不伪造任务状态。摘要仅在内存，不写入 Board 或浏览器存储。
- 参数从高级绑定折叠中移出，画幅/时长/seed 与工作流已暴露创作字段直接可调；任意自定义字段没有用途语义，不按名称猜参数能力。保持原范围、类型、默认值与冻结快照，分辨率只在工作流已有映射时出现。负向词、文字绑定和调度继续折叠。
- 已连接素材显示用途、缩略图及断开入口，替换沿用面板下拉。拖线时高亮匹配且未占用的素材连接口，普通注释线语义不变。不自动替换输入或执行任务。
- 验收：未配置/固定修订/状态、失败保留、直接调参、素材断开/替换/类型提示、只读、桌面/手机/主题/缩放、原输入/生成/多产物/结果组回归；隔离 DB 与 Mock，不请求真实模型。
