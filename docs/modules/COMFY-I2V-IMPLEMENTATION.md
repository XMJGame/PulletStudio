# ComfyUI 图生视频首帧绑定

新增 `video.image_to_video`。保留现有表、任务、提交恢复和归档。工作流选择 API 图中的 `LoadImage.image`，任务选择当前项目内已归档的固定图片版本。界面展示所选图片并要求明确确认向工作流发送。仅上传这一张图片。

- 改动 generation 契约、配置、任务冻结、Provider 与 Worker。使用既有媒体读取和原件校验。图片版本 ID、名称、大小、SHA256 及 MIME 随任务冻结。复用现有 JSON 字段，无数据库迁移。
- 上限 16 MiB，PNG/JPEG/WebP。通过固定地址的 `/upload/image` multipart 上传，使用任务生成的文件名，`overwrite=false`，只接受对应的输入目录和文件名。提交图引用该文件。上传失败时保持未提交，重启后的准备阶段可复用同名同内容文件。仍需在实际提交前复核权限、工作流、镜头和审批。
- 在现有生成对话框加入图生视频能力、首帧节点配置和图片版本选择。模拟验收覆盖固定版本、实际发送字节、路径拒绝、权限与最终视频草稿归档。对用户主机先进行只读检查，实际测试生成单独确认。
