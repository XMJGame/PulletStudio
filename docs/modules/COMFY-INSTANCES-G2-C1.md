# G2-C1 ComfyUI 实例池与能力检查

复用工作区的生成连接。配置权限继续要求实例管理员和工作区管理权限。管理员明确将连接加入实例池，设置运行和等待队列阈值。每工作区最多 12 个池实例，同一 API 地址只登记一次。连接地址及加密凭据仍由原服务管理。

增量扩展连接的池配置及其独立版本，新增固定工作流修订与实例的检查记录。配置变更使用池版本校验。固定工作流按原图、绑定、公开字段和模型枚举声明检查。健康和队列读取原生 system_stats 与 queue，保存计数和受限诊断。结果附连接和池版本，15 分钟后显示过期。健康、声明匹配、容量及实际试跑是独立证据。

工作流中心新增实例池入口，支持加入或移出、设置阈值及逐实例核对。读写接口使用工作区和项目授权，凭据、地址和上游任务内容留在后端。探测过程使用受信 HTTP，完成后再次检查权限和版本。

本包交付管理和匹配证据。C2 使用这些证据接入事务容量预留、默认自动与指定实例、冻结实例及原 Worker 恢复。当前生成与试跑继续使用各修订绑定的连接。验收使用两个隔离 ComfyUI Mock 验证匹配、负载、失败与范围。实际设备上的并行生成另行验收。
