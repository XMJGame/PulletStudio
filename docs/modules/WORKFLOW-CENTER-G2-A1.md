# G2-A1 工作流中心与技术图预览实施合同

2026-11-05，基线63c14ae。需求/只读参考见[能力对照](../architecture/HERO-INFINITE-CANVAS-REVIEW.md)。代码由Pullet独立实现，不引入上游源码/资源/运行依赖。

- **复用**：GenerationService.config/createConnection/createWorkflow、ComfyProvider验证、GenerationParameters及现有镜头生成对话框；Generation、Job、Storage、Take与Board合同不变。
- **DB/API**：本包无新增表/迁移/API。现有GET generation-config提供管理权限、连接名/状态及不可变工作流元数据；现有POST连接/工作流继续授权、校验/审计。不会新增未经授权的原始工作流/密钥读取接口。
- **UI**：抽出GenerationSettings，供原镜头对话框与新项目WorkflowCenter共用；保留原表单标签/错误保留输入。中心显示已保存工作流及参数摘要、配置入口；只有原canConfigure用户可导入/配置。普通创作者浏览可用配置，不显示地址/凭据。
- **技术图**：独立React Flow只读图，解析本地API JSON的class_type与二元输入引用，显示节点/线/绑定位置；允许选择节点/常量映射到既有正/负/首帧/输出字段，不能改线/执行脚本或任意渲染媒体URL。只显示字段名与类型，默认不回显所有常量（可能有密钥/物理路径）。图是导入草稿的技术预览，保存过的原图查询/版本管理后续单独实施，不冒称已完整可编辑中心。
- **边界/故障**：1–200节点、160KB沿用原限制，并限制预览边数/输入字段数量；检测缺端点/循环供管理员核对，不补造连接，不对外发请求。JSON不合法或上传失败保留原文本/映射；取消/关闭有输入需提示。新中心独立于G1正式Board，浏览器草稿不写Board或localStorage。
- **测试**：独立节点图解析/边界测试；隔离浏览器验证中心入口、已有列表/只读权限、API文件预览及点选绑定、恶意文本/外部URL不执行、失败保留、手机/键盘；原生产生成配置流程回归。无服务端行为改动不为文档/组件提取重复跑全量媒体API；类型/格式/构建及必要浏览器测试必须通过。
- **未交付**：任意动态字段Schema、完整object_info/模型依赖报告、工作流家族/追加修订/审批/归档、测试生成画布、G2-B正式生成节点、G2-C多实例调度。本包不能标整个G2-A完成。
