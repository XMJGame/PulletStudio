# Studio UI V2 接入 C

将工作流中心和提示词库迁入统一的双栏工作区。桌面同时显示列表与详情，窄屏可单独切换列表与编辑区，切换保留当前输入。工作流中心把 API JSON 导入、节点映射和公开参数分区，试跑与发布继续通过现有独立窗口。连接配置按需展开。提示词库集中搜索、正文、修订与应用入口。

沿用 WorkflowCenter、GenerationSettings、WorkflowGraphPreview 和 PromptLibraryDialog 的数据与授权。保持固定修订、冲突和草稿处理、幂等写入、读取失败时隐藏受限内容及试跑证据隔离。React 和 CSS 调整不涉及数据库、API、队列或工作流导入合同。验收包括桌面、390px、浅深配色、只读、未保存输入、修订冲突、固定版本、试跑与发布。
