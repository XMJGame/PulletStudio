## 产品决定

1. 左侧窄工具栏依次提供文本、图片、视频、音频、便签、分组、资源库和上传。图标配悬停名称，当前工具有状态；右键菜单使用同一创建动作。选择/平移/缩放等视图工具单独保留，不混进资源类别。窄屏采用紧凑入口，不以缩小整张桌面界面代替适配。
2. 图片/视频/音频是用户的创作目标和创建入口，不新增三套执行器。点选后在当前视野或右键落点创建对应生成草稿，立即打开配置；已上传素材直接成为媒体卡。卡片区分文字编辑、媒体预览、生成控制、便签及分组，生成卡显示目标图标、任务状态和输入摘要。
3. API 路径为“目标类型 → 平台 → 模型/接口 → 对应参数”；只有真实接入能力才可运行。当前已接入 ModelScope 文生图，视频/音频显示明确未接入状态，不能伪装已有可调用接口；本包不以填任意 URL 代替 Provider Adapter。
4. ComfyUI 路径为“工作流 → 该修订声明的输入/参数/输出”。生成面板取消独立输出类型筛选器；从视频入口进入时可以预筛工作流，但筛选只是找工作流的辅助，不能修改其输出合同。切换至不同目标工作流须明确处理已有绑定，取消时保留原草稿。
5. 工作流中心负责清晰配置输入、创作参数和输出。主输出决定卡片目标类别，附加输出仍可包含其他媒体。工作流缩略图或名称不能替代实际能力校验。
6. 外观采用一个通用输入口、一个汇总输出口。内部保留现有具名端口、固定媒体版本、工作流修订及任务快照。无歧义时自动绑定，有歧义时就近选用途；结果组到下游必须选定具体产物，不自动使用“最新第一份”。
7. 资源选择器为主动打开的网格窗口，右侧可调宽资源库继续用于拖拽，两者复用同一资源查询及权限。项目库/公共库分明；图片/视频/音频分类、搜索、文件夹和已选数量清楚可见。截图中的“主体/画布”不直接照搬，角色/场景/道具和画布切换沿用各自已有入口。

界面采用 Pullet 现有中性色、蓝色交互强调及浅/深主题，不照抄参考品牌、闭源代码或素材。不引入时间线、专业剪辑器、导演台、宿主和模型安装器。

## 关键行为细化

### 创建与目标类型

- 空白图片/视频/音频卡是合法未配置草稿，显示选择生成或导入素材的明确动作，不伪造空媒体、任务或工作流。导入后使用真实 reference 节点；从已有素材发起生成时创建独立 generation 草稿并显式绑定，保留原媒体及历史结果。
- 生成目标提示刷新后保留，选定工作流后按其真实主输出同步。用户编辑参数和固定素材不因切换筛选器静默丢失。不同媒体的尺寸单位、时长和质量选项只展示实际支持的项目。
- API 平台/模型设置仍在全局设置；画布只选择可用能力，不展示凭据和实例地址。已有任务不因模型配置变化重新解释。

### 映射配置

- 输入必须说明：创作者名称、媒体类型、用途、相对顺序、节点/字段、必填与缺失策略。不能按“图片1”的展示编号代替稳定槽 ID。
- 标量参数必须说明：名称及单位、控件类型、图内默认值、允许范围/步长或枚举。`0.4 MP` 表示约 40 万像素预算，实际宽高由工作流节点按比例及对齐规则计算；不能直接标为 0.4K、分辨率百分比或固定 480p。
- 主输出与附加输出分别选择节点、历史字段和媒体类型。预览/中间产物不自动当成正式主结果；数量来自真实工作流，不以外观“一根线”限制批量产物。
- 选节点可建议绑定，但必须由配置者确认。自动读取 `/object_info` 复用已有受控后端连接和元数据解析，不在浏览器绕过实例权限直连。

### 单一端口

- 文本唯一提示词槽时可自动绑定；多个文本输入角色需要明确选择。首尾帧、多参考等同类媒体必须按已保存用途映射。便签不自动参与执行，旧便签的显式提示词绑定继续兼容；文本 brief 作为提示词来源的统一映射在 B21 同步前后端实现。
- B15 当前依赖选中生成节点后读取固定定义；B21 可在拖入时按目标懒加载并显示加载状态。加载失败不建伪边，确认时再次校验工作流及占用；不全量预取所有图，也不猜测。
- 结果未完成时可查看任务状态，不把尚不存在的媒体接入执行。用户挑选的固定产物保持稳定，后续重跑不会替换下游输入。自动执行整条链路不在本包范围。

## 验证与交付规则

每阶段运行构建、类型和对应的有意义测试。前端行为使用隔离数据库及真实媒体/Mock Provider，明确不算真实 GPU 验收。改到 Board schema 或后端参数校验时运行对应 API 契约/授权测试，最终按变更影响运行后端全量；不为纯 CSS 反复跑模型。最终统一运行相关 Board/Workflow/Settings 场景，检查桌面、390px 手机、浅/深主题、125%/150% 缩放及键盘操作。

真实服务只使用用户指定的本机 ComfyUI，必要时执行小分辨率单次代表测试；R2V 模型仍待用户准备，不下载或以其他权重顶替。API 视频/音频接入作为后续独立 Provider 工作包，不让界面布局倒逼未经验证的能力承诺。每阶段验收后再更新包，不直接改运行目录；有数据风险或核心架构冲突时先说明并等待确认。
