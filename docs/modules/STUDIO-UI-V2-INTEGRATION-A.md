# Studio UI V2 接入 A

在重建分支从视觉原型进入项目、画布、素材接入。正式首页复用新版项目卡片与组件令牌，从已授权项目列表读取。项目入口直达画布，打开固定链接或上次画布时重新授权。没有历史偏好时打开最近项目画布，空项目给出明确创建入口。项目创建、回收站、团队和设置保留原接口和权限。

画布使用新的全屏工作空间、窄工具轨、资源抽屉与媒体卡片。复用现有 BoardWorkspace 状态、保存、CAS、视口、固定版本、分组和具名连线逻辑。素材通过原 BoardSources 解析、加入草稿和保存。普通未授权素材不显示，撤权继续由服务端裁定。

原项目中转页由直接进画布替代。工作流中心、项目素材、提示词库和通用任务从画布进入，已有生成执行面板仍沿用现有提交和恢复方式。下一包再迁移生成组合面板。此批不新增 API、数据库或任务状态。

验收包括真实项目列表、搜索、无封面占位、项目直接进入空画布或最后画布、跨项目链接保护、固定媒体引用、恢复旧布局、读者权限及原有素材、工作流和任务回归。视觉评审原型继续独立运行。
