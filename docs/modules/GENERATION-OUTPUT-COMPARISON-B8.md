# B8 同批次产物对照

基线 332b841。复用正式画布 BoardCandidates、B6/B7 的固定产物、媒体预览及逐份操作。本包仅 Web，无 DB、API、Worker、Provider 或任务快照变更。

## 实施范围

- 将画布候选对照身份从任务 id 细化为主结果 jobId / 扩展产物 outputId。首份主结果和旧单结果任务保持原身份；批量主结果及预览/中间产物均可参与。
- 主侧保留历史任务及产物选择；对照选择器列出已加载任务的具体文件，优先选同一任务另一份产物。两侧选择独立，不共用同任务输出状态。同一媒体版本不同时显示两份；切换历史导致对照不再有效时，提示重新选择，不静默换成新任务。
- 开始对照后固定两侧身份，新任务、刷新与入库响应不会抢走选择。每侧沿用自己的 mediaVersionId/outputId，独立下载、入库、加入画布及复用提示词；只读不提供写操作。
- 仍最多两份预览，桌面并排、手机上下。更换文件或退出对照卸载对应播放器；媒体失败保留固定引用，另一侧仍可用。无同步播放、混音、剪辑、评分或自动选片。
- 修改 BoardCandidates.tsx 和 GenerationOutputPicker.tsx，必要时微调现有候选样式。自由生成/试跑保留逐份选择，本包不新增第二套对照面板。既有跨任务对照继续支持。

## 验收

隔离数据库、Mock 工作流、真实媒体字节。浏览器验证同批两份图片/视频、混合音频产物、两侧独立切换、相同文件排除、稳定身份、独立入库与固定画布节点、下载实际字节、媒体失败恢复、退出播放器释放、历史任务及只读。检查桌面/390px 手机和键盘操作，回归原跨任务对照。运行构建、类型、格式和相关浏览器测试；API 未变不重复跑全量后端。真实模型验收独立进行。
