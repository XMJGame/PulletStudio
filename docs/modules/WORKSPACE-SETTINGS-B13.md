# B13 · 工作台统一设置与左右配置布局

2026-11-09 用户将 ComfyUI 与 API 设置收进工作台侧栏底部的「设置」，项目/画布不再提供配置入口。统一左侧分类及对象导航、右侧当前配置；手机在导航与详情之间切换。覆盖 B12 的顶部双 Tab 入口决定，保留其业务能力。

- 复用 Generation/Provider/Secrets/RBAC、原工作流编辑/修订/诊断/试跑与 API 凭据接口。无数据库迁移，不改变工作流所属项目、旧任务或路由，不把项目工作流直接变成跨项目模板。
- API：增加工作区 GET/POST generation-connections，复用原连接查询/创建路径和原管理权限，让没有项目的工作区也能配置实例。原项目路径继续兼容。管理员外不返回实例地址/凭据，跨工作区拒绝，POST 仍要求实例与工作区管理权限。
- UI：SettingsDialog 统一壳、导航与关闭保护；ComfyInstances 左侧实例列表/新增，右侧单个实例；WorkflowCenter 复用编辑逻辑，列表进入统一左栏，明确项目筛选，切换项目须确认该项目未保存草稿；ApiConnectionsPanel 左侧平台选择、右侧对应表单。其他部分不因切换而卸载、丢失草稿。高级设置按需展开。
- 入口：项目首页侧栏底部设置按钮，手机顶部提供同一入口；移除用户菜单的 API 独立入口、画布顶部 ComfyUI 和更多菜单的工作流/API 配置入口。生成时保留模型/工作流/参数选择。
- 权限/失败：工作区切换隔离整个设置状态；保存失败不丢草稿，凭据不回显、不持久化到浏览器存储；关闭与刷新提醒，忙时禁止切换和重复提交。已有版本冲突策略继续复用。
- 验收：空工作区添加实例、跨工作区/成员拒绝、原项目兼容、左导航右详情、实例/工作流/API 草稿跨分类保留、项目切换保护、关闭保护、桌面/手机/主题/键盘及完整工作流/生成回归。使用隔离数据库与 Mock，不请求真实模型。体验版更新保留原数据与回退目录。
