# 工作区公共媒体库

## 独立工作台入口增量包

本包新增 workspaces/:workspaceId/public-library 的文件夹、列表、移动、移除与媒体读取入口。沿用同一 WorkspaceLibraryService 与 ResourceAccess，使用显式 Project/Workspace scope；工作区入口不需要源项目或任意占位项目权限。收录与导入仍走原项目路径，不创建隐藏项目，不扩展普通私有媒体 URL 的权限。无数据库变更。

前端在 StudioProjectGallery 的工作区工具栏增加公共库管理窗口，复用 PublicLibraryPanel、LibraryFolderControls 和主题系统，按需加载。工作区窗口只浏览、整理、预览和下载，进入项目后可添加素材到项目。关闭预览与窗口需恢复焦点；切换工作区销毁旧列表，未授权或失败显示可重试信息。验收覆盖没有项目的成员、工作区隔离、管理者/普通成员权限、项目原入口回归、桌面/手机及键盘操作。公共库直接上传和结构化资产仍在后续包。

2026-11-07 增量包验收完成。API 249 项、画布浏览器 27 项通过，构建、类型和格式通过。新接口在没有项目权限的成员和空工作区验证读取、封面、范围下载、隔离与管理限制；浏览器覆盖工作台文件夹、异常重试、焦点、保存关闭保护、工作区切换及普通成员入口，实际检查桌面深浅主题和 390px 手机截图。无新增迁移，测试使用隔离数据。实现新增 WorkspaceLibraryBrowserController、WorkspaceLibraryDialog，复用原公共库服务、组件和文件夹控件。

## 项目入口首包

2026-11-07。按用户确认的公共库与项目库方案实施。首包支持图片、视频、音频主动收录、公共文件夹、预览、搜索和添加到项目。角色、场景、提示词和工作流继续由原模块管理，后续分包接入。

公共库归属工作区。所有工作区成员可浏览；素材上传者或源项目管理者可收录已入库的固定媒体版本；收录者和工作区管理员可移除公共条目，文件夹由工作区管理员管理。受保护声音样本、试跑证据和未入库候选不能收录。统一 ResourceAccess 服务覆盖列表、预览、下载与导入，保持现有项目读取检查。普通成员不会取得源项目其他数据权限。

本包是主动归档与导入，不代替产品基线中的可撤销共享授权。公共条目固定原媒体版本并保留引用，移除为软删除；已成功添加到项目的媒体属于目标项目，其后不依赖公共条目的可见状态。此规则来自本轮用户确认，后续指定项目/用户的共享仍需独立实现可撤销权限。

复用 MediaService 的上传意图、校验、媒体探测、恢复登记、Storage Provider 与项目版本归档。现有 media_versions.object_key 为唯一键，首包显式添加到项目会生成受控的独立项目文件，通过服务端流式传输，不要求浏览器重新下载上传。公共库收录本身只登记固定引用。暂不改写已有媒体表的所有权和存储格式。后续对象去重须独立评估，不以放宽唯一约束或项目鉴权来实现。

新增 workspace_media_folders、workspace_media_resources 和 workspace_media_imports。资源使用乐观锁、软移除和请求去重；导入记录绑定目标项目、原公共条目和上传意图，保留来源并支持失败重试。待完成的导入在归档提交时重查公共库及目标权限，内容必须与源校验一致，普通上传和恢复路径也执行相同检查。

API 放在 projects/:id/public-library 下，由当前项目解析工作区，文件夹、资源列表、收录、移除、媒体流和导入均经服务端授权。前端复用 BoardSources 与文件夹控件，在本项目/公共库间切换。公共素材须先添加到项目，再通过原固定项目引用进入画布和生成。无新的队列、跨项目直接 Board 引用或动态脚本。

验收包括两项目收录/导入、不同工作区隔离、无源项目权限的成员预览、声音样本与试跑拒绝、只读导入拒绝、移除后项目版本可用、导入去重/恢复、字节一致性、权限变更时阻止提交及桌面/手机操作。测试使用隔离数据库和真实媒体字节。生成迁移前备份并在副本验证。

代码入口为 assets/resource-access.service、workspace-library.service/controller、MediaService、BoardSources、PublicLibraryPanel 和复用的 LibraryFolderControls。0047 增量迁移固定来源及导入记录，未改写已有媒体表。导入来源通过媒体详情的 librarySource 返回，保持源项目其他资料私有。列表标记当前项目已拥有的素材，减少重复添加；同一导入请求可重试并恢复原上传意图。
