# 公共结构化资产复用

2026-11-07。本包支持角色、场景、道具从项目资源库收录到工作区公共库，并以固定修订添加到其他项目。继续使用 EntitiesService、EntityRevision、媒体绑定、ResourceAccess、MediaService、项目文件归档和原 Board 引用。声音身份与声音样本不进入本包，避免扩大既有样本授权。公共资产直接编辑/创建、跨工作区分享及可撤销 Project/User 授权后续独立实施。

收录者须有源项目编辑权，且为资产创建者或项目管理者；每份参考图须为自己的已入库图片，或具备源项目管理权。原试跑证据、未入库候选、声音样本和已撤销修订拒绝收录。收录整体授权所选修订及其图片给工作区成员，不将参考图另行混入公共媒体列表。固定源修订和全部参考图，源项目后续改名/修订不自动替换公共条目。未收录的资产、其他修订和无关媒体继续私有。后续撤销源修订或新增保护会阻止继续预览/导入。

增量增加 workspace_entity_resources、workspace_entity_imports、workspace_entity_import_media。公共条目固定源实体/修订/项目/工作区，分类使用原公共文件夹并支持 CAS、审计与软移除。导入父记录固定资源、目标项目、操作者和请求标识，子记录绑定每份源图与项目上传意图。参考图通过原流式检测归档到项目，相同图片用于多个角色位时只导入一次。上传/恢复/最终提交均重查权限与源版本；最后事务复用 EntitiesService 创建新的草稿实体并登记固定实体修订及来源。已完成请求重试返回原导入修订，不随目标后续编辑切换；源公共条目移除后，已完成的项目资产仍可使用。

部分参考图已成功导入但资产尚未完成时，不返回资产成功；图片属于目标项目并保留，重试使用原上传记录继续。不会将原审批状态或审批事件复制到目标。所有任务和画布继续引用目标项目原实体/媒体版本，不创建跨项目 Board 引用，不覆盖现有作品。

项目公共资产详情只向当前操作者返回自己的 pendingImportKey，用于刷新后续接原导入。已有同一操作者/项目/资源的未完成请求时，新请求标识会被拒绝并提示刷新，不创建另一套上传记录。该标识不展示在创作界面。已完成请求固定到目标导入修订，实体详情和导入图片 API 保留来源。

API 使用原项目/工作区 public-library 前缀，增加 entities 列表/详情、分类/移除、授权图片读取；仅项目入口提供收录与导入。前端复用 BoardSources 和 PublicLibraryPanel，增加公共库「媒体 / 角色与场景」切换、类型/名称/文件夹筛选、固定修订详情、参考图预览和添加到项目。项目资产卡片按固定 ref.revisionId 收录，导入完成回到项目资产列表。保护声音身份、失败输入、请求重放及焦点。

验收覆盖历史修订固定、角色/场景/道具属性与图片角色完整性、无源项目权限的工作区成员、跨工作区隔离、声音/试跑/撤销拒绝、导入与媒体恢复、响应丢失、部分失败、源条目移除后的独立项目版本、审批不继承、分类分页及桌面/手机。迁移前备份，在副本检查旧数据和外键。
