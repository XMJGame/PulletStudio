# B5 生成引擎与输出类型选择

2026-11-09 后续调整见 [B19](CANVAS-CREATION-PLAN-B19.md)：ComfyUI 移除独立输出类型筛选，API 保留三类目标选择，分类草稿保存可选 creationTarget；执行仍以固定工作流为准。下文为 B5 历史交付，不再驱动恢复 ComfyUI 的重复筛选器。

基线 e733e23。复用 BoardExecutionPanel、GenerationDialog、已保存工作流摘要和原 ModelScope 项目配置接口，不新增 DB、API、Provider 或执行队列。

## 修改范围

- 共用引擎/输出类型控件：ComfyUI / API · ModelScope，全部/图片/视频/音频。全部类型保持首次浏览全部工作流的兼容行为，选定工作流后跟随其实际能力。筛选只影响选择列表，不决定真实输出，不自动选其他工作流或提交任务。
- 画布：已有节点继续显示固定工作流。读取旧修订后派生引擎/类型，不能被列表头版本替换。明确切换到不匹配类型或引擎才清除工作流和参数、具名媒体参考；提示词及其绑定保留。首帧只在选择支持首帧的 I2V 时保留，其他切换在同一次布局更新中清除。已归档媒体和结果不删除。
- 自由生成：复用同一筛选控件，API 引擎通过现有幂等配置接口获取固定文生图模型；API 任务不读取 ComfyUI 路由、不提交实例 routing。清除不适用的首帧、参考和参数，保留正负提示词、来源和提示词库修订。固定修订试跑不提供引擎/类型切换，只显示当前类型。
- 交互：无匹配工作流、归档/停用、扩展能力未接通均明确提示并阻止执行。API 尚仅接入文生图，选择视频或音频不会伪装支持或静默切换引擎。API 配置失败保留原工作流和草稿。类型选择不写入旧快照；工作流 ID 仍是生成与画布持久化的事实来源。

## 验收

使用隔离数据库和 Mock。验证两入口筛选、旧版回读、切换清除媒体但保留文本、失败保留草稿、API 无实例请求、空配置和只读；切换本身不创建 Generation Job。检查桌面/390px 手机、键盘与浅深主题，回归原媒体生成/提示词/固定结果流程。真实 ModelScope/GPU 验收仍独立安排。
