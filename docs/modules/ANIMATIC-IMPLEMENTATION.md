# 顺序时间线与低清预演实施合同

复用有效选片与固定来源采集、项目RBAC、完整卡、MediaService归档和FFmpeg工具。生成迁移前已执行在线备份。本包只追加表和可空媒体来源列。

- 新增timeline_revisions，项目内连续版本、UUID幂等键、冻结源快照/选片/批准/制作卡、预演配置和有序Clip。片段引用确切Take和媒体版本，保存整数毫秒位置、入点、请求时长及实际对齐时长。单轨顺序、最多24片段/300秒/原件合计2GiB。25fps输出按40ms向上对齐，界面展示实际预演时长。
- POST /projects/:id/timeline-editor 返回范围内选片及默认片段，原声计划inspect/replace且实际有声音时留待明确选择。POST /projects/:id/timelines/preview 校验顺序、唯一镜头、视频边界/图片停留、keep/mute和快照；POST /projects/:id/timelines 冻结配置并CAS追加，GET分页版本和指定快照。音频选片提示本轮需要图片或视频。
- 新增animatic_jobs。POST /timelines/:id/animatics 创建幂等任务，独立worker持久化排队、独占租约、心跳及失败状态。同库同时执行一个任务，过期租约可恢复。支持取消待执行和执行中任务，完成只在文件探测及媒体归档/结果登记后出现。任务不修改Take或选片。
- FFmpeg以参数数组执行，受权存储流复制到独立临时目录并核对字节/哈希，限制解码器/协议、线程、超时和总片长。片段统一低清尺寸/25fps/PCM声音，视频保留或静音、图片补静音，再拼接H.264/AAC MP4。核对实际尺寸/帧数/时长/声音后归档。临时目录经绝对路径核对后清理。
- MediaService为任务上传增加可空animaticJobId，沿用租约、登记恢复、媒体历史和读取接口，origin=animatic。公众上传/手工恢复不能接管任务上传。恢复时优先复用已归档原件，完成和审计同事务。执行前、复制后和登记前复查创作者权限及源选片。
- 前端新增“时间线与预演”，编辑顺序和片段，预览位置及对齐时长，保存版本后排队/取消/查看状态/播放/下载。冲突保留输入，明确重载，失响应同键重试。历史预演保留快照，读取继续核对当前项目及源文件权限。
- 隔离自动化验证范围/边界/毫秒对齐/声音策略、跨项目/角色/CAS/幂等、源变化、真实图视频拼接/FFprobe、keep/mute音频能量、并发/取消/租约恢复、归档失败恢复、备份与撤权。Edge验收编辑/保存/排队/播放/下载、390px和键盘。30–60秒混剪另由接口验收覆盖。

2026-11-05范围更新见ADR-009：此合同的既有轻量预演保持兼容，不继续扩展独立多轨、转场、关键帧、调色、特效或专业混音。声音素材与字幕文件交接按真实来源另包，不把专业剪辑器列为后续。
