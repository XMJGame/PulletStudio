# G2-A3 受控试跑与项目发布

试跑复用现有 Generation Job、提示词与首帧校验、资源确认、Worker、Storage 和恢复流程。配置管理员从工作流中心选定固定修订与项目现有镜头，使用已保存的提示词与参数表单。产物标记为试跑证据，保留项目内预览和下载权限。素材库、首帧选择、资产引用、画布引用及 Take 只消费生产素材。试跑和生产共用单镜头任务并发限制。

新增 Job 用途字段和试跑完成状态，并由数据库保护用途和结果归属。新增工作流发布事件表，记录目录、固定修订、试跑证据、操作者、意见、动作和顺序。迁移只追加结构。工作流中心创建和保存的修订采用审核模式。已有工作流及兼容 API 调用维持原可用规则，采用审核模式后该目录的新修订继承门禁。

项目审核权限可发布当前头修订。证据须为同修订、当前连接版本的完成试跑，且连接可用、目录未归档。发布版本在项目内共享。编辑和恢复产生草稿时，团队仍可使用之前发布的版本。发布替换、撤回使用目录版本保护和幂等请求键，保留原任务、试跑和发布历史。跨项目模板共享另行确定授权。工作流试跑和发布证据只保留业务标识、说明与时间，连接凭据和原图继续沿用原管理权限。

新增固定修订试跑历史、试跑排队及发布历史和写入接口。工作流中心提供固定修订的试跑入口、结果预览、发布与撤回。生成表单复用现有控件。验收覆盖未发布阻断、试跑隔离、错误证据、权限、冲突、幂等、旧版本兼容及原生产回归。运行使用隔离 Comfy Mock。
