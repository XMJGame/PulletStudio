# Studio 视觉与交互规范

创作内容占据主要视野。背景安静、控制项易扫读，动作只在可用时露出。项目主页使用卡片与大图封面建立浏览层次。画布采用点阵、窄工具轨与工作流组合区，资源抽屉浮在边缘。媒体节点以画面占满卡片为主，端口和状态只占很小区域。

2026-11-06 配色收尾：用户认可布局，要求借鉴 DX OS 浅深截图的中性层次，同时保留 Pullet 的特点。保留原创 P 标识、项目/画布结构、浮动生成面板和候选对照；以灰白/炭灰、黑白动作、克制蓝色引导形成自己的影视创作空间，不复制参考项目的窗口系统、品牌或资源。旧墨绿主题被本规范覆盖。

| 规则 | 默认值与用法 |
|---|---|
| 表面 | 浅色 `#f6f7f9` 工作区、白色卡片、`#f0f1f3` 次级表面；深色 `#1c1f24` 工作区、`#24262c` 面板、`#2e3138` 次级表面，整体保持中性 |
| 文本 | 主要文本接近黑色。大标题 34–42，卡片标题 15–17，正文 13–14，元信息 11–12。中文优先系统中文字体 |
| 动作 | 浅色主按钮 `#303238` 配白字，深色主按钮 `#eef0f4` 配深字；焦点、选中和执行连线使用蓝色。成功/警告/失败保留独立语义色与文字，不用绿色铺满产品表面 |
| 尺寸 | 4px 基础间距，常用 8/12/16/24/32。常用输入和按钮 36–40px，工具轨图标按钮 40px |
| 圆角、层级 | 普通控件 8px、卡片 14px、组合面板 18px。轻描边界定表面，浮层使用两级软阴影 |
| 图标与动效 | 统一 24px 线图、1.7px 描边。过渡 140ms，尊重减少动效设置 |
| 可访问性 | 可见键盘焦点，图标按钮有可访问名称。折叠面板提供清晰的关闭入口，任务变动有状态文本 |

`shared/styles/studio-tokens.css` 是样式来源。`shared/ui` 提供按钮、图标、品牌标记、主题和基础输入语义。原型用现有 React/CSS 和 React Flow验证，暂不增加另一套 UI 框架。随着正式页面迁移，表单、弹窗、下拉和状态组件使用同一组令牌。
