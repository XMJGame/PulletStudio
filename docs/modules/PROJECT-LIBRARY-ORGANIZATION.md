# 项目资源库整理

资源库支持左边缘拖动宽度和项目共享文件夹。桌面宽度为 240–560px，随视口保留画布可用空间，偏好按用户保存。键盘方向键调整，双击恢复默认。手机继续使用适配宽度。

首版使用一级文件夹，同时整理媒体和语义资产。分类属于素材身份，历史文件版本一起归类。全部资源和未分类保留入口。新建、改名、移入和删除使用项目编辑权限及版本冲突检查，删除文件夹时其内容回到未分类。已有文件、资产修订及画布固定引用继续使用原身份。

数据库仅增加 library_folders 和 library_placements。分类绑定媒体资产或语义资产，复合外键保护项目和工作区。沿用原 BoardSource 查询，文件夹筛选在分页之前完成，与类型和关键词共同生效。变更入口为 GET/POST /projects/:id/library-folders、PATCH/DELETE /projects/:id/library-folders/:folderId、POST /projects/:id/library-placement。界面沿用 BoardSources，增加分类、创建/改名和逐项移动。

验收覆盖创建重放、重复名称、分类分页、跨项目和只读拒绝、并发移动冲突、删除回未分类与已有画布引用不变，以及拖动、键盘调宽和刷新恢复。测试使用隔离数据库。可选音视频和纯音频输出继续按 B3 后续合同实施。
