# B9 单任务产物批量入库与原件包

基线 9953cb9。复用 Generation/MediaService/RBAC、B6/B7 固定产物及现有 yazl ZIP 能力。不改数据库，不新增队列、存储 Provider 或审批流程。

## 修改范围与接口

- 单次已完成的无镜头生产任务可勾选主结果/扩展产物，最多 40 份。标识由系统传递，主结果用 null，扩展用 outputId；拒绝空、重复、未知、跨任务选择。试跑、未完成和旧 Shot 任务不接入。
- `POST generation-jobs/:id/save-outputs-to-library` 接受 `{outputIds:(UUID|null)[]}`。与原单份入库共用校验和写入方法，项目编辑权限，先验证全部所选文件，再在一个事务内入库，失败全部回滚。重复请求不会重复归档或增加媒体版本。原单份接口保持兼容。
- `GET generation-jobs/:id/output-package/preview?outputIds=main,UUID...` 预检选择、权限、类型及总大小，返回下载地址及数量/字节数；不宣称完成原件完整性检查。`GET generation-jobs/:id/output-package?...` 在读取原件前再次授权、校验全部原件，再流式返回 ZIP。无需先入库，只读成员可下载有权读取的生产产物。
- 原件包仅含已选文件和 manifest.json，记录固定媒体版本、任务/工作流身份、文件路径、类型、尺寸、时长与校验信息，不含凭据、工作流原图或提示词。按 Video/Audio/Images 分类，序号前缀避免重名，路径安全。单包至多 40 份、原件合计 2 GiB，沿用素材包限制。只返回所选文件，不自动加入其他任务/项目或旁白字幕。
- 复用现有媒体存储的完整性与权限检查，将流式 ZIP 通用实现提取至 exports/verified-zip.ts，保留旧已选素材包的文件结构、限制和历史下载行为。流式读取仍逐文件及读完后检查授权和校验；中途错误/撤权/取消中断 ZIP，不产生成功归档或磁盘缓存。
- 前端共用 GenerationOutputBatchDialog：画布候选与自由生成进入，默认不勾选，支持全选/逐份、只读下载、逐份已入库状态及数量。入库结果一次更新原任务，网络/权限失败保留选择，可安全重试；操作期间保护关闭。打包由浏览器原生下载，界面只表示已发起，完成/中断以浏览器下载记录为准，避免将大 ZIP 全部载入前端内存。试跑不显示入口。

## 验收

接口测试覆盖原主结果兼容、混合产物 ZIP 独立解包/逐字节及哈希校验、只含已选文件、批量事务故障回滚和请求重放、跨任务/只读写入/撤权/试跑/未完成拒绝、缺失/损坏原件、下载中断与旧素材包回归。浏览器覆盖两个入口、默认空选择、全选/键盘、只读下载、失败/丢失响应重试、实际 ZIP 下载、操作关闭保护、任务到来后固定选择和桌面/手机。真实模型、大文件压力及可恢复下载记录不属于本包。

2026-11-07 完成。API 全量 276 项、画布全量 36 项、工作流全量 21 项通过，构建、类型、格式和文档链接通过。新增接口验收覆盖事务内故障与审计回滚、重复请求无重复版本/入库事件、空/重复/超限/未知及跨任务选择、只读写拒绝、试跑和未完成拒绝、所选音频新增声音样本保护后的下载拒绝、损坏原件、读中撤权及取消。ZIP 使用独立读取器解包，校验数量、固定身份、目录、所选原件字节与 SHA256，确认不含提示词、服务地址或工作流原图。共享工具改动后的旧素材包 14 项完整通过，保留历史 ZIP 的字节兼容及原件故障检查。

浏览器从画布和自由生成分别完成原生 ZIP 下载并解包校验；确认在选中扩展产物时打开批量窗口，首份主结果仍是原主文件。响应丢失后的安全重试、预检失败保留选择、后台新任务到来后仍处理原任务、操作中关闭保护、键盘勾选、返回焦点及只读下载均通过。实际检查桌面浅色和 390px 深色/浅色截图。

无数据库迁移，正式库只读检查仍为 42 条迁移。测试使用隔离数据库、Mock 和小型真实媒体，不代表大文件压力或具体模型实机兼容性已验收。
