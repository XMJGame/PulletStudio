# L2-B 项目提示词库实施合同

2026-11-06，基线 7720fda。新建独立于 Shot 的普通文本提示词库；不恢复旧编译器，不接 AI 改写、不开放跨项目共享。

## 复用与修改

- DB 追加 `prompt_library_entries` 身份/当前版本与 `prompt_library_revisions` 不可变文本修订。项目/工作区归属、作者、请求键/哈希、标题、正负词、标签、来源、可选推荐固定工作流；CAS 和事务审计。只增表和触发器，原数据/迁移不改写，生成前先备份。
- API `prompt-library/`：项目列表/搜索（20条游标）、创建；按身份读取当前/指定版本、历史（20条）、追加修订。项目 read/edit 授权，不同项目的推荐工作流和来源修订不可绑定。幂等重放先于版本冲突；失败回滚头/修订/审计。
- Generation 共用现有入口，新增可选 `promptLibraryRevisionId`；校验同项目及正负词匹配，任务快照冻结来源身份/修订/名称与实际文本。编辑文字则 UI 清除固定来源，旧 Job 不随库变化。
- Board v1 只增补便签可选提示词元数据（负词、来源、固定库修订），文字容量与生成文本统一为16000；保留256KiB布局上限。旧便签/注释边语义不变；保存时校验来源，编辑文字清除修订绑定。不是执行节点或第二套画布。
- Web `prompts/` 共用库窗口：项目首页、通用生成、画布入口；保存/检索/标签、复制、指定版本应用、历史查看、冲突保留输入；生成窗口和便签可保存到库，插入画布保留完整正负词和固定来源。

## 验收

无 Shot 创建/搜索/复制/跨画布复用；历史版本不被覆盖；修订库后旧任务文本不变；只读/跨项目/撤权/回收站、CAS、重复请求、分页、事务失败、重启和升级保留旧数据。库绑定内容不匹配应明确失败，不能伪造来源。浏览器覆盖桌面/390px、复制与失败输入保留，沿用隔离 Mock，不调用真实 GPU。

首版不做变量模板、收藏/最近使用、跨项目授权、归档删除、批量生成或模型能力扩展；它们不阻塞完整文本的保存与使用。
