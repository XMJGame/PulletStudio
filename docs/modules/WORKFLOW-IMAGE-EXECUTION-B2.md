# L3-B2a 多张参考图片执行

基线 5358f4b。通过自由生成与管理员试跑交付第一条多参考执行路径。复用 ComfyUI 的图片上传和任务提交接口。[ComfyUI Server Routes](https://docs.comfy.org/development/comfyui-server/comms_routes)

| 范围 | 实施 |
|---|---|
| 工作流 | 所有扩展槽位为必填图片、输出仍为一个主产物。按已保存槽位顺序注入。可选槽位、音视频及扩展输出继续显示原因并拒绝执行 |
| API | 项目任务与试跑接受按槽位 UUID 指定的固定图片版本。原首帧仍独立。拒绝未知槽位、缺图、跨项目、试跑证据及类型不匹配。历史返回名称、版本与槽位 |
| DB | 沿用 snapshotJson 保存有序引用和文件校验信息。增量触发器拒绝旧 Worker 领取新任务。无需修改表或重写数据 |
| Worker | 同一实例顺序读取校验并上传。文件名固定为任务加槽位。上传前及提交前重查授权，提交不确定时复用现有核对流程 |
| UI | 自由生成与试跑复用项目图片列表和分页。画布节点的具名参考绑定留在 B3 |

验收使用隔离数据库和 Mock。验证同一请求重放、不同槽位映射冲突、真实文件字节、旧 Worker 拒绝、权限变化和单产物归档。现用数据库先做在线备份。真实模型由用户环境独立验收。
