# G2-C2 自动选机与指定实例

有实例池的工作区在生产表单默认自动。高级指定仅列该工作流修订已匹配的同工作区实例。旧 API 请求和未建池的表单沿用工作流绑定，试跑继续使用绑定连接。

创建任务在原 SQLite 写事务内完成能力、健康、负载证据和版本检查、选机及任务预留。自动按预计负载排序，指定仅核对指定实例。任务接受后固定实例、连接配置和池版本。超过容量返回可重试冲突。Worker 开始提交前检查同实例的即时队列，达到阈值时等待；新队列和已有任务共享原 Job、租约及归档。已经提交或提交状态不确定时，查询和恢复仍使用原实例。明确取消或结束跟踪后释放预留。

新增任务路由表和旧 Worker 写入保护。API、Web 和 Worker 同版本启用池路由。普通创作者只看到名称、可用性和任务所用实例。凭据、地址与原始远端队列留在服务端。两台隔离 Mock 验证并发预留、固定路由、满载、重新启动与恢复。用户设备上的双机实测另列验收。
