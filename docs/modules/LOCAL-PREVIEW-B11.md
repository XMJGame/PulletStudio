# B11 · 本机体验包与启动验收

用户要求代理完成运行、打包和推送，使用者负责体验反馈。复用已构建的 NestJS API、Generation Worker、React Web、SQLite 迁移和 Local Storage，不增加桌面宿主、第二后端或任务队列。

- 修改：`tools/local-preview.mjs` 负责本机静态页面、流式同源代理和两个既有进程；`tools/local-child.cjs` 转发优雅退出；`tools/package-preview.mjs` 白名单打包。提供双击启动/停止命令与操作指南。
- DB/API/UI：不改业务表、迁移、业务接口和 React 组件。体验包从空库初始化，API 自动迁移仅作用于包内库；仓库现用数据库、密钥、媒体和其他服务不参与。包内独立 `data` 保存账号、媒体、加密密钥和日志；不支持通过体验包直接升级旧数据。
- 分发：Windows x64 本机体验包，包含匹配的 Node、生产依赖及媒体工具和第三方说明；不包含已有 `.env`、数据库、账号、真实 Provider 凭据、用户素材、Mock 或浏览器测试。离线可启动，真实生成仍依赖外部服务及正确工作流。
- 运行：只监听 127.0.0.1，默认 Web 5188/API 3188；后台隐藏进程，工作目录固定，端口占用失败不杀其他服务。启动等待 API 与 Worker 就绪；重复启动验证本包随机控制密钥。停止仅通过本包认证控制端点通知持有的子进程，等待当前 Worker 步骤结束，不取消远端生成。异常退出同时清理本包进程；不按进程名或端口批量结束。
- 权限：仍使用原初始化、会话和 RBAC。初始化密钥只写本地文件，不在 HTTP 静态目录公开；没有默认账号。代理保留 Cookie、Origin、CSRF、Range 和原件下载流；断开下载时取消上游。
- 验收：解包后以自带 Node 从其他目录启动；测试页面/API、实际初始化/登录、真实媒体导入/提帧、持久化重启、重复启动/停止、端口占用、错误控制密钥及不公开本地文件。生成/比较/入库/ZIP 复用 B8–B10 已完成的隔离浏览器验收，不把 Mock 当真实模型证据。干净交付包与 QA 运行副本分开。最终更新状态并推送当前功能分支，不合并 main。

完成证据：实际解包运行专项 7/7（父测试及 6 个子场景），完整画布 37/37 在自带运行时和正式静态 Web 上通过；另覆盖故意移走 API 入口后的失败清理。构建、类型、格式和文档链接检查通过。生成使用 Mock，视频和提帧使用真实 FFmpeg；已检查桌面/手机截图。现用工程库只读检查仍 42 条迁移、完整性 ok、外键 0；QA 新库 54 条迁移。记录见 [实时状态](../IMPLEMENTATION-STATUS.md)。
