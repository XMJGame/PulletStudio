# B16 · 同任务结果组

复用现有 group/result/parentId、GenerationJob 完整产物清单、固定 outputId 与原 Board 保存/授权。仅 Web，无 DB/API/Worker 或自动归档变更。

多产物候选新增「整组加入画布」：用户明确添加任务结果后，主结果及所有已完成产物原子加入一个结果组；不因后台任务完成自动往画布塞入结果。原逐份添加继续可用。已有固定结果不复制、不擅自搬动用户布局；可复用只包含该任务结果的已有分组，容量不足全部不加，重复点击不增加节点。组外已有产物保持原处，提示实际新增数量。

每个子节点独立引用 jobId/outputId，可预览/下载/复用/删除。结果拖出组边界解除父级并保留世界坐标，主动移出入口适配手机。删除组沿用原解散行为，保留子节点与原件；删除子节点不删除媒体。普通手工分组继续可用。

验收：混合产物/批量主结果的固定身份、重复点击、已有单份结果、容量原子失败、保存重载、分组移动/解散/拖出、只读、提帧与后续生成。独立 DB、Mock 和真实媒体，不请求真实模型。失败/排队任务不生成占位假结果。
