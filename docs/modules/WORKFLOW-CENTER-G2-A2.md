# G2-A2 工作流修订、创作参数与依赖报告合同

基线4d68085，2026-11-05。原generation_workflows为不可变定义，Job外键/快照和原Provider/Storage/RBAC保留。实施分为修订目录→标量参数端到端→依赖检查，各自验证，不覆盖旧定义或修改用户ComfyUI。

## 数据与兼容

增加workflow_catalogs与workflow_catalog_revisions：目录保存项目/工作区、当前定义/修订及CAS版本/归档状态；修订只关联原generation_workflows ID，记录摘要/恢复来源/幂等键与请求哈希，不复制graph。旧定义各自成为单版本目录，原行及Job/媒体/Take不改。触发器保护关联历史、范围与连续head；审计同事务。归档阻止新任务，不删除历史/停止已排任务。回滚复制旧定义形成新修订、重新校验，不回退编号。

迁移前在线备份；Drizzle在忽略的独立目录生成，完整SQL/回填/保护写好再登记正式journal，避免开发监视服务抢先应用空文件。旧迁移不改写。升级与实际备份副本核对旧表全部行及完整性。

## API与权限

沿用canConfigure（实例管理员＋工作区管理）及项目read。原POST generation-workflows兼容无请求键，新UI使用UUID Idempotency-Key；重复相同内容恢复原结果，改内容409。新目录修订POST要求expectedVersion＋请求键，版本冲突保留草稿。管理员可读取固定定义、修订历史、按旧修订追加恢复、归档/恢复目录、对固定定义检查依赖；普通读者只取得摘要/创作字段，不返回原图、地址或凭据。各接口先授权，再解析内部对象。

## 字段与执行

workflowInput增加可选fields（最多20项、UUID由界面生成、名称、node/input、text/number/boolean/enum合同）。默认值来自图常量；四种标量类型严格验证、目标不重复且不占用正/负词/首帧/已有三参数；禁止把已知凭据/端点/路径输入公开成创作字段。枚举本包为字符串选项，不声称支持任意媒体输入/任意JSON路径。

Job增加可选fieldValues，服务端解析默认/覆盖并验证未知键、类型、范围/步长/文本长度/枚举；冻结在原snapshotJson及实际提交图，幂等核对包含字段值。Worker按冻结图重新验证声明。旧无fields/fieldValues定义及Job按原语义读取，不重写快照。创作者表单由Schema渲染，无需填写字段ID/节点ID。

## 依赖报告与界面

只通过后端受信连接读取object_info，限定并发/总时限/类型数量与结果大小；检查节点存在、必需输入、引用端点/输出、常量类型/范围及枚举（包括声明中的模型文件选项）。动态/未知Schema明确未验证，网络失败不报兼容。报告不含端点/令牌/文件系统路径/整份上游对象，不调用prompt、不扫描或下载模型；“声明匹配”不等于显存充足/文件完整/真实运行成功。

工作流中心显示当前修订、归档、历史、追加修订/回滚及依赖结果；共享GenerationSettings加载旧定义形成可编辑草稿，错误/409/不确定响应保留，明确放弃后才能切换。普通镜头生成表单展示动态字段，继续既有成本确认/任务归档。技术图不变成执行DAG，Board仍不调用模型。
