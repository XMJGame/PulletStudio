# 画布直接导入

保存后的可编辑画布接受本地图片、视频和音频拖入，并接受剪贴板图片。正文输入、可编辑元素和其他弹窗继续处理自己的粘贴事件。文件拖放的位置转换为画布坐标，资源库拖放继续沿用原合同。

复用媒体上传意图、二进制传输、探测、归档及媒体固定版本解析。抽取 MediaDialog 已使用的上传与断线恢复逻辑供两个入口共用。一次最多 20 份文件，顺序上传，实际类型与大小由原服务核验。每份文件具有独立请求键，失败重试读取同一上传状态；已经归档的文件可重试加入画布。停止等待会保留未完成条目，已归档素材仍在项目中。

导入窗口展示状态与错误，完成后将固定媒体引用加入当前草稿并提示保存。执行期间窗口阻止无意关闭，用户可停止等待。卸载停止本地等待，引用加入前重新核对当前画布和授权。节点上限、只读与撤权继续生效。

验证覆盖批量图片/视频/音频、拖放坐标与缩放、剪贴板图片、文本粘贴、非法文件、上传断线、成功响应丢失、重复重试和只读。此阶段不新增数据库、后端接口或依赖。
