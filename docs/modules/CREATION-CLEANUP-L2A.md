# L2-A 删除旧创作界面与 G0 原型

2026-11-06 用户明确要求不再保留应删内容，覆盖上一轮「冻结并放入兼容工具」的 UI 决定。新补充方案的项目资产库、多画布、提示词库与有类型工作流绑定作为后续产品方向；不在本批一次实现共享 ACL 或任意多模态执行。

## 影响与最小设计

- 删除 G0 canvas-lab 源码、HTML、独立测试与配置、构建及 CI 入口；正式 React Flow/Board 复用，不维护第二画布。
- 删除旧剧本、自动分镜/提案、结构/分集/镜头编辑、离线编译提示词、预演和旧交付的前端组件及入口；不另设兼容菜单，不把废弃组件挪到 archive/。
- 主应用移除分集/镜头状态与启动时的无关查询，仅保留账户/项目/成员与资产创作导航。生成窗口只承载项目/画布通用输入；工作流试跑只用直接输入。
- 项目资源选择器默认资产/媒体，旧 Shot 引用仍按原固定版本解析，不能把旧注释边解释为执行输入。保留历史媒体下载、Board 和 Job 读取所需的服务端依赖与历史数据库迁移，不清空作品数据。
- 旧 UI 专用的浏览器流程删除；核心账户、项目权限、媒体与生成场景改从实际新入口验收。API 的历史不变量测试继续运行，不为了数字保留已取消界面。
- 本批不扩大资源共享权限、不调真实 GPU、不下载模型、无新依赖或数据库迁移。明确约束是先删无用产品代码，而非删用户作品。

## 验收

类型/构建无残余导入，G0 不再构建或访问；无兼容菜单、剧本/分镜/结构入口；新项目可用素材/画布/通用生成，工作流动态参数与实例调度保留；同项目多画布共用媒体且历史独立。旧 Board 固定引用与项目权限仍可读取，原 API 保护保持通过。更新唯一实施状态与实际删除清单、测试证据。
