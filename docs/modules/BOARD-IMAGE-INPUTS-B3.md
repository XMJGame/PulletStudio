# L3-B3a 画布参考图片

基线 58f7d83。生成节点按固定工作流的槽位顺序选择画布上的图片或已完成的图片结果。选用、替换和移除都编辑具名输入连线，普通注释线保持原语义。工作流切换清除该节点旧的参考图绑定，保留提示词及原首帧的编辑行为。

| 层 | 实施 |
|---|---|
| DB | 沿用 BoardRevision 和 Generation Job 快照。画布 v1 兼容新增 `reference:<槽位 UUID>`，原有布局直接读取 |
| API | 保存校验槽位归属和边结构。执行从固定画布修订解析来源，复用项目媒体、工作流、任务和 Worker 的校验及权限。生成配置可按项目读取已固定的旧工作流摘要 |
| 界面 | 生成面板按槽位选择及预览。参考图连线集中显示于画布节点。任务详情展示实际参考图版本 |
| 失败 | 缺图、不可用图片、未知槽位和过期修订拒绝执行。未保存修改按原画布规则处理 |

验收覆盖固定来源、重复和伪造连线、工作流切换、刷新恢复、画布生成及候选入库。多图执行适用 B2a 支持范围，使用 Mock 验证。

## B3b 可选参考图

增加「可选，留空时断开」策略。首版限专用 LoadImage 的参考图，服务端根据固定图推导其全部下游连接，并以 ComfyUI 的节点声明验证每条连接都可以独立省略。未知、必填、共用文件输入或遮罩等槽位不允许使用该策略。保留旧 `empty` 声明可读和不可执行的行为。

保存校验图和参数占用，执行快照保留实际选中的图片和原工作流。Worker 在验证后只修改提交副本，省略空槽的可选连接及已无引用的专用加载节点。旧 Worker 领取保护使用增量迁移。画布、自由生成和试跑使用同一合同，普通创作者看到必填或可选状态。以隔离 Provider 验证空槽、双图、非独立连接拒绝与工作流回读。

## B3c 必填参考视频与音频

沿用已保存的媒体声明、项目资源权限、Generation Worker 和单主输出归档。按槽位媒体类型查询和固定已有素材版本，允许图片与必填视频、音频混用，旧图片 API 与旧任务保持兼容。视频及音频每份上限 32 MiB，图片仍为 16 MiB，含首帧合计 64 MiB。ComfyUI 原生文件上传使用 multipart，视频和音频文件放入实例 input 根目录，适配原生加载器的文件枚举。上传前后继续校验权限、哈希与返回路径。旧 Worker 领取保护单独增量迁移。

画布连线保留媒体类型，选择器按槽位筛选。自由生成和试跑分页读取同类型项目版本。本包验证上传字节、类型与任务恢复，不改输出类型，也不自动添加视频解码、重采样、音轨拆分或可选音视频断开。源工作流必须已显式连接这些节点。
