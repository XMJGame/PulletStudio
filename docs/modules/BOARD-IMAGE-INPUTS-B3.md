# L3-B3a 画布参考图片

基线 58f7d83。生成节点按固定工作流的槽位顺序选择画布上的图片或已完成的图片结果。选用、替换和移除都编辑具名输入连线，普通注释线保持原语义。工作流切换清除该节点旧的参考图绑定，保留提示词及原首帧的编辑行为。

| 层 | 实施 |
|---|---|
| DB | 沿用 BoardRevision 和 Generation Job 快照。画布 v1 兼容新增 `reference:<槽位 UUID>`，原有布局直接读取 |
| API | 保存校验槽位归属和边结构。执行从固定画布修订解析来源，复用项目媒体、工作流、任务和 Worker 的校验及权限。生成配置可按项目读取已固定的旧工作流摘要 |
| 界面 | 生成面板按槽位选择及预览。参考图连线集中显示于画布节点。任务详情展示实际参考图版本 |
| 失败 | 缺图、不可用图片、未知槽位和过期修订拒绝执行。未保存修改按原画布规则处理 |

验收覆盖固定来源、重复和伪造连线、工作流切换、刷新恢复、画布生成及候选入库。多图执行适用 B2a 支持范围，使用 Mock 验证。
