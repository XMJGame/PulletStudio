# 阶段实施合同

本目录记录各工作包**开工时**的复用路径、DB/API/UI、权限、故障与验收边界。它们是增量范围，某份早期合同里写“审批后续”不代表后续没有实现；当前状态只见[IMPLEMENTATION-STATUS](../IMPLEMENTATION-STATUS.md)，使用入口见[文档导航](../README.md)。

已完成的合同保留以追溯决策，不重编号、不按其历史“下一包”重复施工。产品边界以[ADR-009](../ADR-009-production-and-postproduction-handoff.md)为准；[画布ADR-008](../ADR-008-creative-canvas-reference.md)目前只是决策与原型安排，尚无已完成的画布合同或性能证据。

下一次恢复开发前，按实时状态写G0最小合同，明确实验入口、依赖/许可、比较数据、交互/性能门槛、退出条件和测试；不能把所有Board/Skills/Agent提前塞进同一包。
