项目 API 直接接受外部正负词、工作流修订、参数、首帧和可选 Board 上下文。项目范围幂等、持久队列、实例路由和响应丢失核对继续使用原实现。通用结果完成后不创建 Take，归档复用 MediaVersion。媒体资产新增库内标记，候选初始库外，显式保存幂等加入库，旧资产默认库内。

自由创作可用已保存工作流，管理员独立试跑可用项目输入；正式发布保留为团队镜头路径。默认项目空间提供生成、画布、素材、结果，剧本和分镜置于兼容区域。画布工具栏调用相同通用生成表单，固定 Board 归属，结果可添加正式媒体引用。

必要验收包括无剧本、无 Shot 的 T2I 和单首帧 I2V、关闭后任务继续、重启和丢响应核对、库内保存和结果复用、权限隔离、旧完整制作链回归，以及有旧任务和 Take 的迁移比对。实机模型验证沿用此前独立 I2V 证据，首批新增链路用隔离 Mock。
