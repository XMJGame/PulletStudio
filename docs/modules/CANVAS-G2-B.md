# G2-B 画布镜头生成与候选

以画布现有镜头引用节点作为生成入口。检查器显示固定制作卡版本，当前版本可打开生成表单。历史版本可查看候选，用户可明确更新节点引用再提交。画布通过原镜头生成 API 提交固定制作卡版本、已发布工作流修订、已保存提示词、创作参数和必要的首帧版本。首帧可明确选择画布图片。连线表达创作关系。

复用 GenerationDialog、Generation Job、Worker、Storage 和 Take。创建任务事务校验画布制作卡版本、当前发布及原权限。保留同请求键的原任务回放。关闭画布后从镜头任务记录恢复跟踪。画布布局和业务提交分别保存，沿用 Board v1 数据合同。本阶段无数据库迁移。

镜头候选从现有 Take API 分页读取。两栏可选固定媒体版本并预览图片、视频或音频，显示尺寸、时长和审核状态。使用原候选审核面板进行提审、批准及选片。项目编辑者可明确把候选原件加入画布草稿，保存时沿用固定媒体引用授权。

验收覆盖画布提交与关闭后归档、同镜头候选比较及审核选片、过期制作卡和撤回发布的服务端阻断、兼容镜头入口和手机布局。模型执行使用隔离 ComfyUI Mock。
