# ComfyUI 单镜头生成实施合同

首批支持项目内单镜头文字生图和文字生视频，每任务归档一个明确配置的输出文件。保留现有 SQLite、项目权限、固定提示词、资产准入、媒体归档和草稿 Take。标准 ComfyUI API 格式工作流由管理员配置。生成连接、工作流及任务分别登记。新增工作流版本使用新配置记录，旧任务继续读取固定记录。

- 使用已批准的工作区连接。端点及工作流配置限同时具有实例与工作区管理权限的账户。端点沿用地址批准规则，固定解析地址，拒绝重定向。工作流节点由操作者信任并配置，平台仅替换明确指定的正负词输入。首批绑定文本与单个输出位置。自动参考媒体上传、参数矩阵、批次及插件模式后续增加。
- 新增连接、工作流和任务表，给既有上传意图追加可空生成来源字段。图、版本、正负词及任务输入由服务端冻结。排队须确认提交，校验当前完整卡、已保存提示词及固定资产审批。独立 Worker 在提交前重新核对。超时或响应丢失进入待核对状态，核对仅查远端历史。任务未提交时允许取消。
- 远端历史只取指定节点和字段中的单个输出，安全取回到现有流式导入，保留真实探测及文件校验。文件完成登记后，在同一 SQLite 事务保存草稿 Take 与任务完成。重启后以任务绑定的上传意图复用归档，避免重复版本或 Take。
- 前端增加镜头“媒体生成”入口，包含连接与工作流设置、选择已保存提示词、任务状态、核对及取消。后端保留详细技术证据。
- 验收以隔离数据库、真实媒体样例和模拟 ComfyUI 为主。测试图片与视频、权限、幂等、丢失响应、重启和归档。真实工作流按用户提供的地址与 API 格式文件另外联调。

接口参考 [ComfyUI Server Routes](https://docs.comfy.org/development/comfyui-server/comms_routes) 与 [ComfyUI 服务端实现](https://github.com/Comfy-Org/ComfyUI/blob/master/server.py)。
