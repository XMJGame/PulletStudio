# Studio UI V2 接入 B

选中生成节点后在画布内打开创作面板。面板展示工作流、首帧缩略图、提示词和提交入口。负向词、便签绑定、动态参数和实例调度按需展开。底部操作区独立于内容滚动。最近一次任务及其候选可就地查看，其余任务可展开。图片和视频继续使用受保护的生成媒体地址。

保留 BoardWorkspace 的布局、草稿保存和固定资源绑定。BoardExecutionPanel 复用现有 generation-config、节点任务、自动与手动调度、幂等提交和候选入库接口。节点任务固定实际修订、工作流和媒体，保存冲突留在画布，提交断线沿用同一标签页的请求键。已有全项目任务窗口继续承担取消、核对与重试。只读角色可查看许可范围内的任务与候选。布局分组和节点移除仍从节点操作进入。

验收使用隔离 SQLite、真实测试媒体及 Mock ComfyUI。覆盖桌面和 390px 视口、首帧和提示词、参数、保存冲突、断线重放、只读、候选播放、画布加入、入库与跨画布复用。此批仅改 React 和样式，不新增数据库迁移或 API。
