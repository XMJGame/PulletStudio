# 画布创作体验实施合同

基线 b07d0a5。以用户提供的 Infinite-Canvas 截图为交互参考，在现有 React Flow 画布独立实现。桌面画布默认浅色，可按设备切换深色。右侧素材缩略图库可折叠，节点详情与生成面板按选中内容显示。

第一条验收路径为项目图片拖入画布，从图片直接发起生成，查看实际首帧，填写提示词或选用项目提示词库，选择固定工作流，保存并生成。可从画布打开原素材导入窗口。拖放创建固定引用，使用现有服务端授权和保存校验。

生成面板以现有便签和具名端口为输入，直接编辑时更新绑定便签，应用库版本时创建独立便签并连接。图片快捷入口创建生成节点和首帧绑定。常用参数留在主区，其他设置可展开。

保存并生成由前端依次调用现有修订与执行 API。保存冲突保留草稿，保存成功后只用返回的固定修订提交。若入队失败，可在该修订重试，任务幂等键沿用原机制。两个操作各自持久化，保存成功后即使任务失败，已保存修订仍可继续使用。无需迁移。

结果可预览、加入画布或直接入库。同项目其他画布复用同一个媒体版本。桌面与手机检查，浏览器使用 Mock 走通拖放、提示词、保存与生成、结果与入库，并回归冲突、只读和撤权。跨项目授权、多参考、直接粘贴文件和图像编辑单独安排。
