# P1-A：画布中的资产版本与参考素材选用

2026-11-06，开工基线 cbb1d57。复用正式 Board，属于既有资产交互接入，不是多参考生成或共享权限实施。P0 的最终配色认可与合并门禁保持待确认；不合并 main。

## 现状与本包结果

画布资源库当前只列资产当前修订，预览只显示其中一张媒体。已有实体修订、角色/场景参考位置和媒体授权接口可复用，用户不应为了选旧造型或侧面参考离开画布。

- 在资源预览内选择资产固定修订，分页读取历史；选择历史后添加的仍是该 revisionId。
- 显示所选修订的参考素材及用途，可查看不同图片/声音样本。
- 明确区分“添加资产版本”和“添加此参考素材”。前者固定实体修订，后者固定 MediaVersion，可沿用已有单图片生成入口；查看其他参考不修改资产主图或已保存节点。
- 资产卡补充简短描述及可理解的版本状态。媒体卡和现有预览入口保持兼容。

## 修改范围与复用

| 层 | 修改/复用 |
|---|---|
| DB | 无迁移、无新表、无作品数据改写 |
| API | 不新增接口。复用 GET entities/:id/revisions（before 分页）和 POST projects/:id/board-references/resolve |
| 前端 | BoardSourcePreview、BoardSources、参考预览样式；提取资产修订选择组件以保持职责清楚 |
| 固定引用 | packages/contracts/src/board 的 entity revisionId 与 media id 原样使用，不改执行端口 |
| 权限 | 原项目 RBAC、声音样本限制及固定引用服务。每次切换修订/参考都经服务端重新解析，不靠缩略图 URL 推断权限 |
| 生成 | 原单图片输入、Job/Worker/Provider/Storage 继续复用；本包不提交真实 GPU，不宣称 IMAGE[]/R2V 已可用 |

## 故障与退出条件

- 切换版本立即隐藏上一版本媒体与添加入口；切回、关闭、搜索、跨项目变化后的旧响应不能污染新预览。
- 历史列表失败有重试；拒绝访问时清空不可用历史。选定版本/媒体失败不退回其他版本，不静默采用最新。
- 只读用户可选择/预览版本，但没有添加入口。私有声音、撤权及跨项目检查沿用后端规则。
- 自动化以隔离 API 和原创合成媒体验证：旧修订/不同用途媒体的准确固定引用、刷新恢复、删除节点不删文件、版本分页、快速切换的过期响应、失败重试、只读/权限拒绝。
- 正式页面检查桌面/390px、深浅主题、键盘入口；运行构建、类型、格式和 Board 回归。没有 API 行为改动时不重复已有全 API 套件；保留基线与本包证据区别。
