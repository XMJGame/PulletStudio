# 工作流创作参数实施合同

本包复用单镜头生成服务、ComfyProvider、不可变工作流记录及 GenerationDialog。先交付可选画幅、时长秒数、seed 三项，采用声明的节点与输入位置，保持任意 API 图和模型兼容。项目设定保留为创作意图，生成时明确选择工作流参数。

- 数据库沿用 definition_json 和 snapshot_json。工作流配置新增可选 parameters，图中当前常量作为默认值。旧配置和任务缺省为空。任务冻结最终参数值及已替换的图，Worker 继续提交固定图。无迁移。
- POST generation-workflows 验证绑定指向已有常量，与文本及首帧位置互斥，各语义及目标唯一。画幅声明可选原始字符串和显示名称，秒数声明范围及步长，seed 限安全整数。向目标节点声明核对 STRING/枚举、FLOAT/INT、远端数值边界和默认值。秒数的上游输入由管理员按实际工作流定位，平台保留图内帧换算逻辑。
- generation-config 仅返回参数合同及默认值，不公开完整图和连接凭据。POST generation-jobs 增加可选 parameterValues，拒绝未声明参数、无效选项、范围和步长错误。省略使用图中默认值，空字符串不自动转成零。同一幂等键比较规范化后的实际参数，改变参数须产生冲突。
- GenerationDialog 配置界面增加三项可选绑定及约束输入。普通生成表单按选定合同渲染控件和发送摘要，修改参数清除发送确认并更新幂等键。任务显示冻结参数与现有 FFprobe 元数据。
- 验收使用隔离数据库和模拟 ComfyUI，覆盖非法/重叠/连线绑定、远端类型和边界、参数规范化、幂等冲突、API/Worker 重启后实际提交值及旧任务兼容。Edge 验证管理员配置、修改后重确认、失败保留输入、桌面/手机及任务实测信息。沿用已有媒体归档验收。
