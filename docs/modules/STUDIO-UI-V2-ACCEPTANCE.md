# Studio UI V2 整体验收与清理

检查正式项目、素材导入、工作流导入与映射、生成节点、候选入库和跨画布复用的完整路径。补充一条通过 UI 贯穿主要步骤的浏览器验收，外部模型使用 Mock，媒体处理使用真实测试文件和 FFmpeg。

所有常用弹窗跟随应用主题，包括项目创建与设置、素材、生成任务、资产和团队。复用原 Dialog 的焦点、退出和忙碌状态，保留工作流与画布专用布局。清理已无调用的旧页面 CSS 和重复的画布配色定义，使用共享令牌。只移除经代码引用核对的样式。

继续使用现有 API、权限、不可变版本、任务和数据库。验收覆盖浅深色、桌面与手机、上传与生成结果、保存恢复、旧引用、权限和冲突。汇总分支差异、实际测试与剩余范围供用户评审。
