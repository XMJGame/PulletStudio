# B6 扩展产物归档与选择

基线 df36a1f。复用 Generation Job/Worker/ComfyUI/Storage/媒体探测及固定工作流，不创建第二队列。

## 实施范围与兼容

- 保留 job.mediaVersionId/result 及旧结果节点语义。主输出仍恰好一份；已声明的 preview/intermediate 扩展输出允许单份或每槽最多 8 份，总扩展最多 32 份。未声明的远端输出不收录，临时文件、重复文件描述、缺失或超量输出拒绝，不静默截取。
- 新增 generation_outputs 记录固定槽位、位置、类型、描述、上传和媒体版本。原 media_uploads 单任务主上传唯一约束不变；扩展上传在原媒体服务中通过产物记录关联任务。开始归档前固定完整远端清单；重试不重新解释历史结果，不重复上传已完成文件。所有文件成功后任务才完成，部分归档不宣称整体成功。
- 只允许项目/画布/无镜头试跑执行扩展输出。旧 Shot/Take 不扩张。扩展上传继承 generation 或 workflow_test 来源，保持候选显式入库及试跑隔离。普通上传/恢复接口不能写任务管理的扩展上传；任务取消、撤权、连接变化及租约沿用原规则。
- API 保留 result/mediaVersionId，兼容增加 outputs。save-to-library 可用 outputId 选择单份扩展产物，省略仍为主结果；不连带收录其他文件。
- 画布 v1 兼容 result.data.outputId，结果节点 id 使用 outputId，旧节点继续用 jobId。后端核对输出确属同项目、同生产任务且已完成。主结果与各扩展产物可独立加入画布及作为后续输入；删除节点不删除文件。
- 画布候选、自由生成和试跑提供产物切换、预览及原件下载。生产结果可分别入库；试跑只预览、不入库、不成为正式画布结果。原对照、历史及固定任务快照继续复用。

## DB / 安全 / 故障

0051 增加新表、索引及保护触发器，兼容扩展 media_asset_identity 和 generation_test_media_guard 两个既有保护触发器，在保留原条件的基础上识别扩展产物关系。不删除或重建旧表，不移除主上传唯一索引。备份后生成迁移并在副本比较全部旧表。新增任务快照及旧 Worker 领取保护；上线统一升级 API/Web/Worker。

清单、来源和完成文件不可改写；上传、结果版本与任务的项目/工作区/操作者一致。旧主结果路径和无扩展任务不变。扩展文件中途失败可以恢复已创建上传；完整性、实际媒体类型、范围下载和权限继续走 MediaService。不能通过扩展上传伪装手工素材或试跑入库。
