# B10 拖动选帧与参考图保存

基线 3f675c6。用户要求用可拖动进度定位，时间显示为辅助。本包为素材工具，不新增时间线、剪辑或第二队列。

## 体验及复用边界

- 共用提帧窗口：项目视频资源预览、画布固定视频检查器及生成视频候选进入。视频播放/暂停、拖动进度条、键盘方向键及前后微调辅助定位；拖动不调用后台。点「提取画面」后调用服务端 FFmpeg，展示实际提取的 PNG，用户确认后保存。保存前不入库；改变时间清除旧静态图，禁止保存不对应的新位置。
- 复用固定媒体版本、MediaService/Storage/FFmpeg 和原上传归档/故障恢复。保存为独立项目图片，原视频不变；可直接加入画布、继续作为首帧或参考图，不自动提交生成。单次一帧，PNG 保留原始像素尺寸（编码和显示方向由 FFmpeg 自动旋转处理），不承诺可变帧率逐帧精确计数。微调按探测帧率，未知时按 40ms；服务端按时间解码首个匹配帧，临近结尾无帧明确提示回退。
- `GET media-versions/:id/frame?atMs=`：需项目编辑权限及原件读取权，拒绝非视频、试跑、无效/越界时间；校验原件后从 Storage 流复制到独立临时目录，限制协议/格式、处理超时、输出大小和进程并发，执行后清理。返回 PNG 与 SHA256，仅用于实际预览。
- `POST media-versions/:id/frames`：正文 `{atMs,expectedSha256}`，UUID 幂等键。服务端重新提取并核对预览哈希，再沿原上传路径归档；登记前重查源权限。重试沿原上传/登记恢复，已完成不重做。源文件、时间或预览哈希不同而复用请求键明确冲突。操作中不允许关闭，网络失败保留预览与请求键。

## DB/API/UI 修改合同

新增 `media_frame_extractions` 固定源媒体版本、时间、预览哈希、项目/工作区/操作者/请求键与管理上传。仅增表和保护触发器，备份后生成 0053；源/上传关系不可变，不改旧行。固定图片 metadata.derivedFrom 记录源版本/时间，origin=video_frame。试跑证据不能通过提帧进入生产。普通上传/恢复不能接管管理上传。

修改 assets 下 frame-extraction-state、VideoFrameService、MediaController、MediaService 的管理上传授权/提交来源；AppModule 注册。前端 VideoFrameDialog 共用滑块/播放器及保存/加入画布；BoardSourcePreview、BoardInspector、BoardCandidates、GenerationDialog 提供入口。资源刷新与固定 Board 引用沿既有接口；无模型或 ComfyUI 调用。
