# 产品 V2：保留、减重与实施顺序

2026-11-06，对照用户提供的完整 [PRODUCT-V2](../PRODUCT-V2.md)、8a130d2 的实际 schema/Controller/UI/测试及本轮改动。V2 是当前方向；旧 MASTER、团队蓝图和 G2 编号保留为历史设计依据，不再推导强制剧本路线。

## 产品取舍

接受「资产—画布—工作流—生成—候选—复用/交付」主线。降低前置条件和操作成本，保持可靠执行、权限与历史追溯。选择性保留命名资产、版本、团队审核及旧镜头生产链，有需要才进入。不能以减重为由删除已有作品或重建一套生成系统。

| 模块 / 实际代码 | 决定 | 现状与处理 |
|---|---|---|
| auth/、AuthorizationService、Workspace/Project RBAC | 保留 | 账户、邀请、成员、编辑/只读、媒体授权不可绕过；不增第二套权限 |
| production/ 项目基础 | 保留并简化 | 自动编号、可选风格、回收站保留；新项目默认创作页；分集计数不再占主标题 |
| assets/ 的 Media/实体/版本，storage/ | 保留 | 本地上传、探测、原件、Range、封面、固定修订、四类语义资产已有；不另建同名资产系统 |
| generation/ Catalog/Revision、图和 Schema、检查 | 保留 | API JSON、只读技术图、标量映射、版本和依赖诊断已做；工作流编辑集中在中心 |
| GenerationService、GenerationWorker | 重构边界 | 同表、同队列、同 Worker；通用任务无 Shot/Artifact，直接冻结提示词；旧路径保持原合同 |
| workflow-release* / 试跑 UI | 简化 | 新增无镜头试跑；个人创作可用已保存固定版本；正式团队发布及旧证据保持可用 |
| generation-routing / instance-pool | 保留 | 自动/手动、容量预留、固定实例、不确定提交核对已有；不添加第二调度器 |
| Web canvas/ / boards/ | 保留并扩展 | 固定引用、保存/修订、冲突保留与媒体预览已有；本轮直开通用生成、结果引用回画布。独立执行节点与数据连线仍未做 |
| 结果入库 | 重构边界 | 新通用结果先为库外候选，不创建 Take；明确保存同一媒体资产入库；原素材默认库内 |
| scripts/ 原文与历史 | 冻结 | UI 移到兼容制作工具；历史读取、修订、恢复、导出和已有写 API 不删，不继续扩展解析能力 |
| analysis/、提案/采纳、文本 Worker | 冻结 | 原数据与流程继续可用；不再投入自动编剧、自动镜头语言/分镜增强；日常自由创作不用启动文本 Worker |
| Production Shot/完整卡、prompt/ 编译器 | 冻结核心扩展、兼容保留 | 仍供已有项目使用；新创作不要求先保存卡、编译提示词或虚构镜头 |
| TakeReview / asset-approval | 分层保留 | 旧 Shot 审核原样保护；普通候选保存不触发制作审批；通用轻量收藏/标记和团队候选审核后续按需做 |
| timeline/、animatic Worker | 冻结、保留可复用能力 | 仅旧轻量预演及 FFmpeg/FFprobe；不开发时间线剪辑、转场、调色和混音 |
| exports/ 已批准选片包 | 保留 | 旧包继续下载；任意项目媒体的通用交付包列后续，不能把旧 Shot 包改名冒充 |
| Web canvas-lab/ G0 | 从主产品移除 | 删掉右上角原型入口；原实验与基准测试只作研究，正式创作进入项目画布；不复制 G0 本地数据 |
| 新提示词资产、角色三视图、多参考/首尾帧、多输出、音频生成 | 按需新增 | V2 场景 B/C/D 尚未完成，按真实工作流合同分批开发，不为某作品/模型硬编码 |
| Agent/Recipe/插件市场、自动装模型、CRDT、SaaS、完整 NLE | 后置或排除 | 不列 V1 门禁、不创建占位模块；专业后期继续交外部工具 |

这轮实际移除的是主产品中的原型入口和强制旧生产前置；没有删除业务表、历史文件或已应用迁移。文档明确要求先冻结历史链，本轮未发现可以在不影响历史依赖的情况下直接删除整个业务模块的依据。

## 分批实施

| 阶段 | 修改边界 | 退出条件 |
|---|---|---|
| L1 本轮 | generation/、assets/、增量 0039/0040、共用生成表单、项目/画布入口、无镜头试跑 | 空项目直接粘贴提示词生成，候选预览/原件/复用/入库/回画布；权限/幂等/恢复、旧链和迁移回归 |
| L2 下一批 | Board 合同版本与画布节点、共用 Job 表单/结果组件、项目任务页 | 提示词/生成/结果独立节点，明确执行数据连线与普通注释连线，刷新恢复上下文；兼容旧 Board v1；收藏/归档和重复执行入口简洁 |
| L3 | Workflow inputs/outputs Schema、Provider/Worker 输入解析、候选结果关联、素材角色 UI | 优先角色三视图多图片与多输出，再按已就绪工作流接首尾帧/音频；一项真实工作流一项验收，不假装当前任意自定义工作流均可运行 |
| L4 | assets/ 提示词模板、轻量语义资产关联、exports/ 通用打包 | 外部提示词作为可复用资产；图片/视频/音频按选中结果交付，manifest 可追溯，无 Shot 也可打包 |
| L5 | 部署/存储适配/多人验收 | 实际素材与多机生产反馈、备份恢复和权限；按真实需求引入共享/批量/审核，避免先造企业级流程 |

不是给每个阶段固定日期；以可验收的使用场景推进。每批在 modules/ 明确接口/数据/UI 与迁移，测试证据写 history/，唯一实时排期为 IMPLEMENTATION-STATUS。当前不换栈、不引入 PostgreSQL/Redis、不调整用户 ComfyUI 设备。
