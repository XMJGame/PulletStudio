# 项目提示词库

画布顶部的提示词库可保存、搜索和复制普通文本。项目内所有画布共用标题、正负向词和可选的标签、来源及推荐工作流。手机端可以在「提示词列表」和「提示词内容」之间切换。

## 保存与使用

1. 新建条目，填写标题和正向词；可选设置中填写标签、来源或推荐工作流。正负词分别最多16000字符，标签最多12个。
2. 生成窗口粘贴文字后，点击「保存到提示词库」。保存后「应用此版本」带入正负词、来源及可用的推荐工作流；提交前检查参数和首帧。
3. 画布工具栏「提示词库」可插入所选版本的便签，完整保留正负词及来源。选中便签后「自由生成」带入文字；也可将现有便签存入库。
4. 修改条目会新增版本。「修订历史」可查看、复制和应用旧版本；历史只读，可「另存为新提示词」。旧任务和画布固定版本不随库更新。

修改生成文字或便签的正负词、来源，会解除该处的库版本绑定，成为独立文本，不修改库。插入和编辑后需保存画布。当前连线仍只记录注释关系，便签不是自动执行节点。

## 查找和协作

搜索匹配标题、正向词或来源，标签按完整标签筛选。列表和修订历史分页读取；正负词分别复制。浏览器拒绝剪贴板访问时，可手动选择正文。

项目编辑者可保存，读者可查看和复制。多人同时编辑时，过期保存被拒绝并保留输入；明确选择「载入最新提示词版本」才替换草稿。切换条目或关闭窗口前，有未保存修改时提示确认。

库绑定由后端校验同项目及正负词一致，不能伪造来源。撤权或回收项目后不能继续读取或应用，已保存作品不清空。当前没有条目删除、收藏、最近使用、变量模板或 AI 自动改写。

## API

| 操作 | 路径 |
|---|---|
| 列表/创建 | `GET/POST /api/v1/projects/:id/prompt-library` |
| 当前版本 | `GET /api/v1/prompt-library/:id` |
| 历史/追加版本 | `GET/POST /api/v1/prompt-library/:id/revisions` |
| 指定版本 | `GET /api/v1/prompt-library/:id/revisions/:version` |
| 指定修订 | `GET /api/v1/prompt-library-revisions/:id` |

写入需 CSRF 与 UUID `Idempotency-Key`，修订需 `expectedVersion`。生成可选 `promptLibraryRevisionId`，冻结实际文本与来源；无来源的原调用继续有效。详见[实施合同](modules/PROMPT-LIBRARY-L2B.md)。
