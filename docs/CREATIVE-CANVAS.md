# 项目创作画布

2026-11-06。正式产品使用 React Flow 和既有 Board/BoardRevision，多张画布共用项目资产。旧 G0 和兼容制作 UI 已删除，见 [ADR-012](ADR-012-remove-retired-creation-ui.md)。

画布现在是项目主视图。按 Esc 不退出项目；「返回工作台」与「切换 / 新建画布」会保护未保存草稿。素材、提示词、历史及管理窗口仍按需打开，关闭后回到原控件。

视频节点显示缩略图、播放入口和已探测时长。点击后直接在节点内播放；同时只加载一个节点播放器，关闭、移出可见区域或离开画布会停止预览。刷新不恢复自动播放。预览不会改变输入、任务或固定媒体版本，播放失败时保留引用并提示检查文件与权限。

资源库默认展示已入库媒体，可以按全部/图片/视频/音频筛选并搜索文件名。切换到「资产」查找角色、场景、道具和声音身份。筛选覆盖项目全部资源再分页，生成候选和试跑证据不会混入媒体库；候选需在任务中显式入库，已有画布引用继续有效。

按住资源库左边缘可左右拖动调宽，刷新后保留当前用户的宽度偏好。双击边缘恢复默认，也可聚焦边缘后用方向键调整。手机资源库使用固定适配宽度。

「文件夹」可切换全部资源、未分类和项目共享的一级文件夹。编辑者可新建、改名、删除文件夹，通过每张素材下的「移至文件夹」分类。媒体和语义资产共用分类入口，其他画布可以继续引用相同素材。删除文件夹后内容回到未分类，原文件和画布固定引用继续有效。

资源库顶部增加「本项目 / 公共库」。公共库属于当前工作区，可按文件夹、媒体类型和名称浏览图片、视频、音频，预览并下载固定原件。上传者或项目管理者可以从项目媒体卡片「收录到公共库」；受保护声音样本和未入库候选不能收录。

在公共库选择「添加到项目」后，服务端归档一份独立的项目素材，再回到项目库。之后可以通过原入口添加画布或用于生成。已在当前项目的素材会显示状态。移出公共库需要确认，已导入的项目版本继续保留。公共库文件夹由工作区管理员整理，条目由收录者或管理员管理。

工作台顶部也可直接打开「公共库」，浏览和整理当前工作区的图片、视频及音频。无需先打开项目，也不会因浏览公共媒体而获得源项目权限。窗口支持预览、下载、文件夹、类型和名称筛选；Esc 先返回预览列表，再关闭窗口，焦点回到原入口。添加到项目请使用项目画布内的公共库。

两处公共库均可点击「上传素材」，一次选择最多 20 份图片、视频或音频，点击「开始上传」逐份归档。当前文件夹作为上传分类，归档前文件夹已删除则回到未分类。完成后素材直接出现在公共库，无需占用项目，也不会自动加入画布。工作区成员都可上传，上传前会提示成员可见范围。

失败时保留文件选择和请求标识，可重新上传；原件已归档但登记失败时可「重试登记」。刷新后重新打开上传入口，可以读取自己的未完成上传，需要重传时重新选择相同名称和大小的原文件。上传时可「停止等待」，已完成归档继续保留。存储根、格式和单文件大小沿用原媒体设置；后台会检查真实内容，不以扩展名代替检测。

公共库内的「角色与场景」支持角色、场景和道具。先在本项目的「资产」分类选定版本，通过卡片「收录到公共库」分享整份设定和参考图；需为资产创建者或项目管理者，参考图也需具备收录权限。普通媒体的收录入口继续保留，声音身份和样本暂不支持公共收录。

收录固定到所选修订。公共库可按类型、名称、文件夹查找资产，点击卡片查看描述、属性和图片位置。添加到本项目后生成独立草稿及图片版本，回到项目资产分类，可继续拖入画布或编辑。原审批不继承，源资产更新不会替换公共修订与已有画布引用。

导入失败可再次添加，沿用本次请求继续已归档的参考图；刷新公共资产列表后也能继续本人的未完成导入。已完成请求重试不会生成重复资产，移出公共库后已导入的项目资产继续保留。工作台独立公共库支持相同的浏览与整理，添加到项目需从项目资源库进入。公共资产直接创建、公共修订编辑及声音身份授权后续实施。

卡片右上角的预览按钮会在资源库内打开固定版本，不添加画布节点。可查看图片、播放视频/音频、读取名称与尺寸/时长，或下载原件；编辑者可明确「添加到画布」。只读用户也可预览和下载授权资源。返回列表或按 Esc 关闭预览，播放器随之释放；预览读取失败时隐藏内容并可重试。

1. 从「我的项目」点项目卡片或「继续创作」。打开上次使用的画布。首次访问时打开最近更新的画布，空项目显示创建入口。
2. 右侧「资源库」可收起。可以点击资产或媒体卡片来添加，也可将卡片拖到画布上的位置。引用使用固定版本。用「导入项目素材」打开原素材窗口，归档后可直接添加到当前画布。
3. 工具栏「切换 / 新建画布」打开列表。布局、节点、注释连线与修订历史各自独立；未保存修改会提示处理。
4. 便签用于提示词或说明；选中便签后点击「自由生成」会带入文字。选工作流和首帧后提交，关闭页面仍由 Worker 执行。
5. 结果先为候选，可预览/下载/复用/入库/添加回画布。项目共享媒体可在另一张画布添加，固定媒体版本不变。
6. 保存画布追加不可变修订，冲突保留草稿，可比较或明确载入最新。引用失效或撤权显示占位，不泄露未授权内容。

## 选择生成引擎与输出类型

生成节点与「自由生成」均提供 ComfyUI / API · ModelScope，以及全部、图片、视频、音频筛选。首次可浏览全部工作流，选定后显示实际类型。没有匹配配置会提示，不会自动切换工作流或提交。工作流类型来自固定定义，筛选不会改变真实输出。

切换到不匹配的类型或引擎，会清除旧工作流参数、参考素材绑定及不适用的首帧，保留提示词和来源；源素材、结果和旧任务不删除。仍选 I2V 时可继续使用原首帧。保存后按选定工作流生成。旧画布保持固定工作流版本，可在选择器看到旧修订，不自动升级到目录最新版本。

API 当前只有 ModelScope 文生图，凭据仍由工作区 API 设置管理。自由生成可直接选 API；配置失败保留原草稿，视频和音频暂使用 ComfyUI。API 不使用本地实例池，含负向词时会保留并提示处理。管理员的固定修订试跑只显示类型，避免改变验收目标。

## 选用资产版本与参考图

资源库切到「资产」，卡片显示当前修订的描述与状态。点击眼睛按钮可在画布内选择固定版本；历史较多时用「更早的资产版本」继续加载。所选修订的参考素材按用途展示，可查看正面、侧面、场景全景或获授权的声音样本。

「添加此资产版本」保存实体的固定修订，保留其设定和媒体关联；「添加此参考素材」只把当前查看的固定媒体加入画布，图片仍可用原「以此图生成」入口。查看其他参考不会改变资产主图，也不升级旧画布节点。完成后保存画布。仅浏览时不添加节点。

只读成员可以选择版本并预览授权媒体，没有添加入口。版本或参考不可用时隐藏内容并提示重试，不自动改用最新版本或其他图片。生成槽位以选用的固定工作流为准。

## 直接导入素材

在已创建的可编辑画布上，可以拖入本地图片、视频和音频，或粘贴剪贴板中的 PNG/JPEG/WebP 图片。左侧「导入本地文件」也可选择文件，支持一次最多 20 份，受剩余节点数和服务器单文件大小限制。文本框和其他弹窗处理自己的粘贴。

文件逐个上传、探测和归档，自动以固定媒体版本加入草稿。拖放时保留画布坐标，批量文件依次排开。完成后点击「保存画布」保存引用。失败条目可以在当前导入窗口重试，也可以停止等待。已归档文件可从项目素材中取回，关闭页面后需重新选择本地文件。

旧 Board 的 Shot 引用仍能解析固定内容和详情，不恢复旧镜头编辑器、生成表单或 Take 比较页面。普通连线仍仅为注释，不触发任务。

## 从生成节点出片

1. 从「媒体」加入一张图片，选中后点「以此图生成」。系统创建生成节点，并把这张图片接为首帧。纯文字生成可从「添加生成节点」开始。
2. 在浮动面板中选择工作流、确认首帧并填写提示词。「应用提示词库」直接展开就地搜索与完整预览，可分别复制正负词，或应用所预览的固定版本；需要编辑或查看修订历史时再打开「管理提示词库」。应用会替换当前节点提示词，并保留正负词、来源和版本，不自动换工作流或生成。展开「输入绑定与参数」可编辑负向词、连接便签、调整公开参数及调度方式，也可拖线绑定。
3. 有草稿时点「保存并生成」。系统先保存当前修订，再用该修订入队。保存冲突时保留草稿，任务不会提交。若已保存但提交失败，可以从这个修订再次执行。
4. 面板内「任务与候选」默认显示最近一次任务。「历史任务」用紧凑列表切换主预览，选择历史后新任务不会自动抢走画面；「查看最新任务」可回到最新记录。有两份结果时可「对照结果」，桌面并排、手机上下显示，最多加载两个候选播放器。对照只用于观察，不包含剪辑、评分或自动选片。
5. 每份候选可分别加入画布、显式入库、下载原件或「复用此次提示词」；复用采用该次任务的完整正负词、来源和可用的库版本，不自动提交新任务。「此次生成记录」可核对固定工作流、首帧及提示词。结果节点需要保存画布，入库结果可在同项目其他画布复用。底部「查看任务与候选」仍处理失败、取消或需要核对的任务。

画布默认使用浅色点阵。可从工具栏切换深色，浏览器会记住选择。分组、修订历史和刷新引用在「更多操作」中。

执行采用手动触发，每次处理一个节点。普通注释线与具名输入线可同时存在。任务继续在后台运行，重新打开画布可在原节点查看。遇到提交断线，可在同一标签页用相同画布修订和调度设置再次执行，系统会核对是否已有任务。

支持文字、首帧和多参考图片、视频、音频输入，归档图片、视频或音频的单个主输出。先把所需素材加入画布，再在生成节点的「参考素材」区按槽位选择。每个槽位只显示同类型素材。通过断开检查的可选参考图片、视频和音频均可留空。保存会记录带类型的媒体连线，「此次生成记录」显示实际采用的文件版本。主动切换工作流后需重新选择参考素材。音频生成结果可播放、下载、存入素材库、加入固定结果节点，并继续作为后续工作流的音频参考。

工作流声明扩展产物后，同一任务可通过「选择生成产物」切换主结果及预览/中间图片、视频或音频。每份产物可独立下载、入库和加入画布，不会连带收录其他文件；多个结果节点分别固定到各自媒体版本，新增卡片会避开已有卡片。只有全部文件归档成功后才显示完成，失败时可继续恢复。试跑产物仅作为证据预览。当前支持每扩展槽位最多 8 份、总扩展最多 32 份，主输出批量和更细的可撤销共享按[实施状态](IMPLEMENTATION-STATUS.md)推进。
