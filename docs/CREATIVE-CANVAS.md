# 项目创作画布

2026-11-06。正式产品使用 React Flow 和既有 Board/BoardRevision，多张画布共用项目资产。旧 G0 和兼容制作 UI 已删除，见 [ADR-012](ADR-012-remove-retired-creation-ui.md)。

1. 进入项目，打开「创作画布」。可创建多张画布；已有画布按用户/项目恢复上次位置。
2. 左侧项目资源提供语义资产与媒体。引用固定身份/版本，不复制文件或随源资产更新自动替换。跨项目素材目前默认不可引用。
3. 工具栏「切换 / 新建画布」打开列表。布局、节点、注释连线与修订历史各自独立；未保存修改会提示处理。
4. 便签用于提示词或说明；选中便签后点击「自由生成」会带入文字。选工作流和首帧后提交，关闭页面仍由 Worker 执行。
5. 结果先为候选，可预览/下载/复用/入库/添加回画布。项目共享媒体可在另一张画布添加，固定媒体版本不变。
6. 保存画布追加不可变修订，冲突保留草稿，可比较或明确载入最新。引用失效或撤权显示占位，不泄露未授权内容。

旧 Board 的 Shot 引用仍能解析固定内容和详情，不恢复旧镜头编辑器、生成表单或 Take 比较页面。普通连线仍仅为注释，不触发任务。

## 从生成节点出片

1. 添加便签并填写提示词，或从项目提示词库插入一个固定版本。图生视频还需要从左侧「媒体」加入一张首帧图片。
2. 点「添加生成节点」，在右侧选择已保存的工作流版本。将便签的 TEXT 输出接到「提示词」，将图片的 IMAGE 输出接到「首帧」。也可用右侧下拉框选择，画布会建立相同的输入连线。文生图和文生视频只接提示词。
3. 核对工作流公开的参数，保存画布，再点「执行生成节点」。任务使用这次保存的画布修订、提示词及固定媒体版本。修改画布后，旧任务仍使用原输入。
4. 在节点任务中预览结果，点「加入画布结果」后保存。每张画布对同一任务只保存一个结果节点。选中结果即可预览或下载，图片结果也可接到另一个节点的首帧端口。候选入库和任务恢复仍在「查看任务与候选」中操作。

执行采用手动触发，每次处理一个节点。普通注释线与具名输入线可同时存在。任务继续在后台运行，重新打开画布可在原节点查看。遇到提交断线，可在同一标签页用相同画布修订和调度设置再次执行，系统会核对是否已有任务。

当前支持文字、单张首帧与单文件输出。跨项目授权和多参考输入按[后续计划](IMPLEMENTATION-STATUS.md)推进。接口与权限详见[实施合同](modules/BOARD-EXECUTION-L2C.md)。
