# 项目创作画布

2026-11-06。正式产品使用 React Flow 和既有 Board/BoardRevision，多张画布共用项目资产。旧 G0 和兼容制作 UI 已删除，见 [ADR-012](ADR-012-remove-retired-creation-ui.md)。

画布现在是项目主视图。按 Esc 不退出项目；「返回工作台」与「切换 / 新建画布」会保护未保存草稿。素材、提示词、历史及管理窗口仍按需打开，关闭后回到原控件。

视频节点显示缩略图、播放入口和已探测时长。点击后直接在节点内播放；同时只加载一个节点播放器，关闭、移出可见区域或离开画布会停止预览。刷新不恢复自动播放。预览不会改变输入、任务或固定媒体版本，播放失败时保留引用并提示检查文件与权限。

资源库默认展示已入库媒体，可以按全部/图片/视频/音频筛选并搜索文件名。切换到「资产」查找角色、场景、道具和声音身份。筛选覆盖项目全部资源再分页，生成候选和试跑证据不会混入媒体库；候选需在任务中显式入库，已有画布引用继续有效。

卡片右上角的预览按钮会在资源库内打开固定版本，不添加画布节点。可查看图片、播放视频/音频、读取名称与尺寸/时长，或下载原件；编辑者可明确「添加到画布」。只读用户也可预览和下载授权资源。返回列表或按 Esc 关闭预览，播放器随之释放；预览读取失败时隐藏内容并可重试。

1. 从「我的项目」点项目卡片或「继续创作」。打开上次使用的画布。首次访问时打开最近更新的画布，空项目显示创建入口。
2. 右侧「资源库」可收起。可以点击资产或媒体卡片来添加，也可将卡片拖到画布上的位置。引用使用固定版本。用「导入项目素材」打开原素材窗口，归档后可直接添加到当前画布。
3. 工具栏「切换 / 新建画布」打开列表。布局、节点、注释连线与修订历史各自独立；未保存修改会提示处理。
4. 便签用于提示词或说明；选中便签后点击「自由生成」会带入文字。选工作流和首帧后提交，关闭页面仍由 Worker 执行。
5. 结果先为候选，可预览/下载/复用/入库/添加回画布。项目共享媒体可在另一张画布添加，固定媒体版本不变。
6. 保存画布追加不可变修订，冲突保留草稿，可比较或明确载入最新。引用失效或撤权显示占位，不泄露未授权内容。

## 直接导入素材

在已创建的可编辑画布上，可以拖入本地图片、视频和音频，或粘贴剪贴板中的 PNG/JPEG/WebP 图片。左侧「导入本地文件」也可选择文件，支持一次最多 20 份，受剩余节点数和服务器单文件大小限制。文本框和其他弹窗处理自己的粘贴。

文件逐个上传、探测和归档，自动以固定媒体版本加入草稿。拖放时保留画布坐标，批量文件依次排开。完成后点击「保存画布」保存引用。失败条目可以在当前导入窗口重试，也可以停止等待。已归档文件可从项目素材中取回，关闭页面后需重新选择本地文件。

旧 Board 的 Shot 引用仍能解析固定内容和详情，不恢复旧镜头编辑器、生成表单或 Take 比较页面。普通连线仍仅为注释，不触发任务。

## 从生成节点出片

1. 从「媒体」加入一张图片，选中后点「以此图生成」。系统创建生成节点，并把这张图片接为首帧。纯文字生成可从「添加生成节点」开始。
2. 在浮动面板中选择工作流、确认首帧并填写提示词。「应用提示词库」直接展开就地搜索与完整预览，可分别复制正负词，或应用所预览的固定版本；需要编辑或查看修订历史时再打开「管理提示词库」。应用会替换当前节点提示词，并保留正负词、来源和版本，不自动换工作流或生成。展开「输入绑定与参数」可编辑负向词、连接便签、调整公开参数及调度方式，也可拖线绑定。
3. 有草稿时点「保存并生成」。系统先保存当前修订，再用该修订入队。保存冲突时保留草稿，任务不会提交。若已保存但提交失败，可以从这个修订再次执行。
4. 面板内「任务与候选」默认显示最近一次任务。「历史任务」用紧凑列表切换主预览，选择历史后新任务不会自动抢走画面；「查看最新任务」可回到最新记录。有两份结果时可「对照结果」，桌面并排、手机上下显示，最多加载两个候选播放器。对照只用于观察，不包含剪辑、评分或自动选片。
5. 每份候选可分别加入画布、显式入库、下载原件或「复用此次提示词」；复用采用该次任务的完整正负词、来源和可用的库版本，不自动提交新任务。「此次生成记录」可核对固定工作流、首帧及提示词。结果节点需要保存画布，入库结果可在同项目其他画布复用。底部「查看任务与候选」仍处理失败、取消或需要核对的任务。

画布默认使用浅色点阵。可从工具栏切换深色，浏览器会记住选择。分组、修订历史和刷新引用在「更多操作」中。

执行采用手动触发，每次处理一个节点。普通注释线与具名输入线可同时存在。任务继续在后台运行，重新打开画布可在原节点查看。遇到提交断线，可在同一标签页用相同画布修订和调度设置再次执行，系统会核对是否已有任务。

当前支持文字、单张首帧与单文件输出。跨项目授权和多参考输入按[后续计划](IMPLEMENTATION-STATUS.md)推进。接口与权限详见[实施合同](modules/BOARD-EXECUTION-L2C.md)。
